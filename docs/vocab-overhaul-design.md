# 単語学習 全面刷新 設計（2026-07-02）

> 2026-06-12 の `vocab-learning-review.md`（P1文脈化・P2誤答設計は実装済）の後継。
> 部分改善でなく、**データ層・学習フロー・出題UIの三位一体の刷新**を設計する。
> 文法道場 (`grammar-dojo-learning-design.md`) の三層「型→混ぜる→実戦」を単語に移植する。

## 前提

ゴールは「単語クイズに正答できる」ではなく **「初見の古文の中で、その文脈での語義を正しく選べる」**。
単語が入試で効く場面は3つ：

1. **傍線部訳** — 多義語の語義選択（文脈が決める。「おどろく」を機械的に「驚く」と訳すと0点）
2. **古今異義語の罠** — なつかし・ありがたし・やがて・あした（現代語の意味で読むと誤読）
3. **敬語 → 人物関係**（文法道場の敬語設計と共有）

## 今回の刷新を駆動する2つの事実

### 1. 原本 Excel の資産の半分しか使っていない

正本 = `F:\古文単語テストリスト (回復済み).xlsx`。`リスト(n)` シート（655行 = 単語×意味）が原本で、現行 `kobunQ.json`（741 qid・365 lemma）はここから作られたが：

| 原本にあるがアプリに無いもの | 内容 |
|---|---|
| **第2例文セット**（古文/訳 列） | 各意味に例文がもう1系統ある。現行は741問中**17問しか複数例文が無い**。取り込めば全意味が2例文になる |
| **空欄化済みテキスト**（例文空欄・訳空欄 列） | 学校テストと同形式の穴埋め。手作業で空欄位置が確定済み＝機械生成より正確 |
| **品詞・敬語 列** | 品詞別出題・敬語モードの土台。現行 kobunQ に無い |
| **リスト5/6（331問）** | 「例文空欄→語を答える」の完成済みテスト問題。品詞テーマ別シート（動詞68・形容詞82・形容動詞61・名詞64・副詞39・敬語30・連語19・連体詞3）まで整理済み |

注意: `原訳 2（ミス有り）` シートの名が示す通り**原本自体に誤りが混在**。取込時に AI 検品を通す（下記）。

### 2. AI の精度が作成当時より上がっている

当時できなかった／粗かったコンテンツ生成が今なら検品込みで回せる：

- **核イメージ**（多義語の「そもそも何」1行。あくがる＝魂が身体から離れる→上の空/さまよい歩く）
- **意味の決め手**（型＋理由＋手がかり。助動詞の decider 層・例文集と同モデル → `/kobun-text-deciders` の流儀）
- **近接語クラスターの設計**（あはれ/をかし、なつかし/ゆかし、つれづれ/つれなし…）
- **原本の検品**（訳ミス検出・出典照合。捏造禁止・Web照合は例文集コーパスと同じ原則）

## 設計：三層「型 → 混ぜる → 実戦」

### L1 型を作る — 「単語カード」で意味の構造を渡す

暗記の単位を「意味の羅列」から**「核イメージ→派生」の1枚**に変える。

- 1語1画面：核イメージ1行 → 意味マップ（sense が核からどう派生するか）→ 各 sense に例文2＋決め手
- 出題は現行4形式を継続（P1/P2 実装済の文脈化・誤答設計はそのまま活きる）
- 例文が全 sense 2つになるので「覚えた例文の再認」を初回から回避できる（出題ごとにどちらかを引く）

### L2 混ぜて鍛える — 弁別クラスター（本丸）

文法道場 L2 と同じ発想：章立てを「単語番号順」でなく**「紛らわしさごと」**に。

| クラスター種別 | 対決させるもの | 例 |
|---|---|---|
| 多義語内弁別 | 同一語の sense 同士 | おどろく＝気づく⇔目覚める（文脈から選ぶ） |
| 古今異義語の罠 | 古文の意味 ⇔ 現代語の意味 | なつかし・ありがたし・うつくし・やがて・あした（modern_traps.json 27語を拡充） |
| 近接語ペア | 意味が近い/形が似る別語 | あはれ/をかし、つれづれ/つれなし、おぼゆ/おぼす |

- 実装は grammar_drills ＋ DrillSession を**そのまま流用**（topic_id = `vocab-trap-1` 等）。スキーマ変更不要
- クラスター選定と作問を AI で行い、人間検品 → apply-drills.mjs 投入（文法道場と同じ運用）

### L3 実戦で使う — 本文転移

`public/texts-v3` は全トークンに**意味ラベル（meaning層）付き**。ここから機械生成する：

- 本文中の kobunQ 掲載語を抽出 →「この文のこの語の意味は？」（正解＝既存 meaning ラベル）
- 授業で読む本文そのものなので文脈知識が転移を助ける（文法 L3 と同一の強み）
- 解答後は TextReader の該当箇所へリンク
- 既存の corpus-examples（箱3以上で実文に切替）はこの L3 の萌芽 → L3 に統合

### 用例バンク — 深く学ぶ生徒のための「用例をもっと見る」

単語ごとの用例は既に**5系統に分散して存在する**が、生徒からは一度に見えない。これを lemma 単位に集約する。

| 供給源 | 規模（2026-07-02 実測） | 特徴 |
|---|---|---|
| kobunQ v2（Excel 取込後） | 全意味 × 2例・出典付き | 基本例文。sense に確実に紐づく |
| corpus-examples.json | 518 qid / 857例 | 教材実文＋訳。既に sense(qid) 紐づけ済 |
| examples-by-lemma.json | 495 lemma | 出典・文脈解説付きの用例辞書 |
| texts-v3 本文トークン | 134 lemma / 約2,900出現 | **意味ラベル＋本文リンク付きの生きた用例**。教材追加で自動で増える |
| grammar_reibun（助動詞例文集 453例） | 二次的 | 文中に重要単語を含む例が多数 |

- `scripts/build-example-bank.py` で集約 → `public/example-bank/<lemma>.json`（**lemma 単位に分割**して必要時 fetch。egress 対策）
- 用例レコード: `{ jp, translation, source, origin, senseId?, textId?, sentenceIdx? }`。sense に紐づくものは意味別に、未紐づけは「その他の用例」に表示
- **教材由来の用例は TextReader の該当文へリンク**（用例ビュー⇄読解の往復＝L3 への入口）
- 出題側の例文供給もこのバンクに一本化する：L1 の例文ローテーション、箱3以上の実文切替（現行 corpus-examples 直参照）はすべてバンク経由に
- AI の仕事（Phase B）：texts-v3 出現の sense 紐付け（意味ラベル→kobunQ sense 照合）、訳の無い用例への訳付与、重複除去。いずれも検品前提

### 横串

- **SRS は現行の Leitner 5箱を継続**。L2/L3 の qid も同じ箱に入り、復習が自動的に「型と弁別と実戦の混合」になる
- **学校テスト対策モード**：リスト5/6 の331問（例文空欄→語）をそのまま搭載。品詞テーマ別。テスト前の需要に直結
- **単語帳ページ（本文から登録）**は L3 への入口として活かす（登録語→カード→クラスタへ誘導）

## データ層再構築 — kobunQ v2

### スキーマ

```jsonc
{
  "qid": "1-1",              // 既存を維持（下記「互換」参照）
  "lemma": "おどろく",
  "pos": "動詞",             // Excel 品詞列（新規）
  "keigo": false,            // Excel 敬語列（新規）
  "group": 1, "sub": 1,
  "sense": "気づく",          // 表記正規化: 現行の「〔 気づい 〕」活用形埋込をやめ終止形に
  "senseCore": "ハッとする",  // lemma 単位の核イメージ（AI生成→検品、新規）
  "decider": {                // 意味の決め手（AI生成→検品、新規）
    "type": "文脈",
    "reason": "…",
    "clue": "…"
  },
  "examples": [               // 全 sense 2例以上（Excel 第2セット取込）
    {
      "jp": "…おどろかれぬる（古今和歌集）",
      "jpBlank": "…〔　　　〕れぬる（古今和歌集）",   // Excel 空欄列
      "translation": "（訳）…",
      "translationBlank": "…",
      "source": "古今和歌集"
    }
  ],
  "clusters": ["polysemy:おどろく"],  // L2 クラスターへの所属タグ（新規）
  "trap": null                         // 古今異義語なら現代語義（modern_traps 統合）
}
```

### qid 互換（重要）

既存の `srs_state`・`word_stats` は qid（"1-1" 形式）に紐づく。**v2 でも qid を変えない**。
Excel `リスト(n)` の 番号/単語/意味 と現行 kobunQ を突合して qid を引き継ぐ ETL とし、
突合不能行（表記ゆれ等）はレポートに出して人間判断。学習履歴の移行スクリプトは作らない（不要にする）。

### ETL パイプライン

```
Excel リスト(n) ─┐
Excel リスト5/6 ─┼→ scripts/build-kobunq-v2.py → 突合レポート → kobunQ.v2.json
現行 kobunQ.json ─┘        （既存qid継承・空欄/品詞/第2例文取込・sense正規化）
                                ↓
                  AI 増補バッチ（核イメージ・決め手・クラスター・検品）
                  ※ 捏造禁止・出典 Web 照合。8GB機のため逐次1バッチずつ
                                ↓
                          人間検品 → 本番反映
```

## 出題形式・UI 刷新

- **単語ホーム再設計**：教程順「L1 カード/クイズ → L2 クラスター → L3 実戦」を1画面に。官位ゲーミフィケーション・単語王は維持
- **空欄形式の採用**：Excel の空欄テキストで「訳空欄→意味を書く」「例文空欄→語を復元」の2形式を追加（記述＝生成効果。既存の形態素採点 `gradeWithMorph` を流用）
- **単語カード画面**（L1）：既存 vocab HTML（544ページ）と統合し、核イメージ・意味マップ・決め手を上段に。下段に「用例をもっと見る」→ 用例バンクビュー（意味別・出典付き・教材由来は本文リンク）
- 範囲選択・4形式などの現行導線は残し、デフォルトを教程順に寄せる

## 効果の根拠（1行ずつ）

- 検索練習・間隔反復 → SRS（実装済・継続）
- 構造化 → 核イメージ＋意味マップ（senses が1つの絵にまとまり、暗記量が減る）
- **交互練習** → L2 クラスター（番号順ブロック練習では弁別は育たない）
- **転移適合** → L3 本文出題（練習の処理＝本番の処理）
- 生成効果 → 空欄記述2形式（再認より強い）
- 誤りからの学習 → 誤答時に決め手1行を表示（文法 v2 基準と同じ）
