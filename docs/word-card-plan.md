# 浮かぶ解説カード（WordCard）の計画

作成 2026-10-16。元になった試作は `F:\A2A\_work\kobun-story\①月の琴.html`（縦書きの物語。語に触れると意味・理由・品詞・訳が出る）。
2026-10-16 ユーザー指示で、CODEX の担当範囲（ホーム・単語クイズ・SRS・文法道場・位階）も Claude Code が引き取り、この計画に含める。

## 目的

語の解説を「語の近くに浮かぶ短いカード」にし、単語には「この文脈でその意味になる理由」を付ける。読解ページから始め、単語クイズ・検索・単語帳にも同じカードを使う。

## 段階1　読解ページ（済・未コミット）

- `WordCard.tsx`：語・基本330の番号・意味・決め手（analysis の decider。無ければ hint）・助詞助動詞は品詞/接続/用法/活用型・単語帳の意味の一覧・「→ 単語カード」`/word/:lemma`・「もっと」で従来の GrammarPopover。
- `useWordCard.tsx`：PC は重ねるだけで出てクリックで固定（Esc・外クリック・スクロールで閉じる）。スマホは指を当てている間に出て、横になぞると指の下の語に切り替わり、離すと消える。タップで出したまま、同じ語の再タップで閉じる。縦はページのスクロール（`touch-action: pan-y`）。状態は教材画面に持ち、文をまたいでなぞれる。
- `TextReader.tsx`：全教材で既定オン。下部の「解説：カード／従来」で端末ごとに戻せる（`localStorage kobun-word-card=off`）。読解(5)・識別(6)は従来どおり。画面下の帯に、触れた語のある文の現代語訳（高さ固定）。
- `vocabLookup.ts`：本文の下線の判定を別名表（`resolveVocabKey`）にそろえた。
- 検査：`src/tests/wordCardLayout.test.ts`（判定と置き場所）、Playwright で PC（重ねる・固定・Esc・もっと・切替）とスマホ（なぞり・タップ固定・縦スクロール）。実機は未確認。

残り：実機（iPhone・Android）の確認 → 「仏の御石の鉢」で先生方に見てもらう → コミット・本番。

## 段階2　「理由」のデータ

- 置き場所：`public/analysis/<id>.json` の `tokenAnalyses[].decider`（meaning / type / summary / cues）。今は主に助動詞。単語にも同じ形で付ける。UI の変更は不要。
- 対象：単語帳（330）に紐づく語の全出現（助詞・助動詞は既存の決め手のまま）。2026-10-16 時点で 119 教材・5,371 語。公開中の 17 教材（default/nishi の両 cohort とも同じ 17 本。`node --env-file=.env.local scripts/_stats-readonly.mjs` で確認）は 617 語。順番は公開中 → 残り。
- 数える：`npx tsx scripts/vocab-deciders-count.ts`。材料の書き出し：`npx tsx scripts/vocab-deciders-extract.ts <id> <outDir>`（文・訳・語・候補の意味・核・総則・教材のポイント）。検証と合流：`node scripts/vocab-deciders-apply.mjs <id> <out.json> [--write]`（type・summary の長さ・cue.text が本文に1回だけ、を検査してから既存を保持して合流）。
- 作り方（月の琴と同じ手順をスクリプト化）：教材から「文＋語＋意味ラベル」を書き出す → 分担して理由を書く（40〜90字。文脈の手がかりを具体的に。辞書で照合、出典を記録）→ 機械検査（全語にある・字数・ラベルと矛盾しない）→ 別の担当が通しで点検 → 反映。
- 型（後接・呼応・形・主語・文脈）を付け、既存の「決め手」と同じ色で出す。
- `scripts/check-texts.mjs` に「紐づく語に decider がある」検査を足す。
- 公開教材の分は反映前に教員が確認する。

## 月の琴との照合（2026-10-21）

「カードがうまく出ていない」との指摘で、試作 `①月の琴.html` の `#tip` / `place()` / touch 処理と一行ずつ比べた。直した差：

| 症状 | 原因 | 月の琴の作り | 直し |
|---|---|---|---|
| カードが語から 12px 下にずれる（矢印が語を指さない） | カードが `<main>` の `space-y-3` の子で `margin-top:12px` が付く（fixed でも margin は効く） | 独立した `#tip` | カードに `margin:0` |
| 矢印が出ない | 外側を `overflow-y:auto` にしていたので枠外の矢印が切れる | `#tip` は overflow visible、`#tipbody` だけスクロール | 外側 visible・内側 `bodyRef` だけスクロール。矢印は `z-index:-1` で中身の後ろ |
| カードが画面いっぱいまで伸びる | 上限が `100vh - 帯` | `max-height: min(52dvh, 440px)` | 同じ上限（JS で計算） |
| タップで固定した瞬間に下へ飛ぶ／語に被さる | 「上を優先」を `held` で判定していたので固定で外れる。固定で背が伸びても置き直さない | 指の操作は常に上を優先。タップ時に `place()` をやり直す | `touch` を状態に持ち固定後も上を優先。`pinned` の変化で置き直す。上に入り切らず下に入り切るなら下 |
| 固定ヘッダに重なる | 上端の下限が 8px | 本文の枠の上端より上に出さない | `header` の高さを測って `avoidTop` |
| スクロールすると消える | スクロールで閉じていた | 固定中は語について動き、語が画面外に出たら閉じる | 同じ（rAF で置き直し、ヘッダと帯の間から出たら閉じる） |
| 指を当てている間に「クリックで固定」が出る | 操作の種類を見ていない | この行は無い | `touch` のときは出さない。帯の文言も「クリック／タップした語の説明」 |
| 単語帳の語にカーソルの変化が無い・固定中の語の地が灰色 | — | `.w{cursor:help}`、固定中は青い地（`--v-bg`） | `isVocab` を TokenSpan に渡し `cursor-help`、固定中は No. の札と同じ青い地 |

残した違い（ユーザー了承済みの古文単独自）：語 22px・意味 20px、基本形・活用の行、「→ 単語カード」「もっと」、PC で固定したときも帯を出す。
検査：`src/tests/wordCardLayout.test.ts`（10件）＋ Playwright（PC: 重ねる・固定・追従・画面外で閉じる／スマホ: 指を当てる・タップ固定・追従・再タップで閉じる）。実機は未確認。

## 月の琴との再照合（2026-10-25）

「カードの出方がちょっと違う」との指摘で、`place()` と touch 処理をもう一度一行ずつ比べた。前回「直し」に混ぜた独自判断が主因だった。

| 症状 | 原因 | 月の琴の作り | 直し |
|---|---|---|---|
| 指で触れた語が画面の上半分だと、カードが指と手の下（語の下）に出る | 前回「上に入り切らず下に入り切るなら下」を足していた | 上の余地が `min(カードの高さ, 画面の3割)` 以上なら必ず上。入り切らない分は上端で止める（語に少し被ることがある） | **月の琴より一歩進めた**（ユーザー指示「改良してベストを模索」）：上に最小の高さ（160px）があれば上に出し、**語に被らない高さまでカードを縮めて中をスクロール**させる（`placeCard` が `maxHeight` を返す）。下に出すのは上に 160px も無いときだけ。縮めて続きがあるときは下端に薄いぼかし。指の点が語の枠の外なら指の点 ±14px を基準にするのは月の琴と同じ |
| 出る瞬間にふわっと浮く | `animate-popover-in`（0.15s の fade＋4px 上昇＋scale） | アニメ無し。`display:block` で即座に出る | クラスを外した |
| 固定中にページを送ろうと本文に触れた瞬間に閉じる | 外側の `pointerdown` で閉じていた（指のスクロールも pointerdown から始まる） | スクロールでは閉じず語について動く。動かさずに離した（タップ）ときだけ閉じる | 指で本文（root）に触れたときは pointerdown では閉じず、`onTouchEnd` の `tapOutcome` に任せる。本文の外（帯・ヘッダ）は従来どおり |
| スクロール追従で、語をまたいで反対側へ飛ぶ | 追従のたびに上下を決め直していた | 縦書きなのでスクロール軸と上下が直交し、位置関係が保たれる | 同じ語・同じ固定状態の追従では、今の側に最小の高さが取れるうちは側を変えず高さだけ変える（`placeCard` の `current`）。取れなくなったときだけ反対側へ |

残した違い（上に加えて）：PC は試作が「語の横」に矢印なしで出すが横書きでは下が相当なので、上下＋矢印のまま。← → キーで前後の語へ移る機能は無い。なぞって離したあと試作は最後の語の青地が残るが、古文単は消す。
置き場所の考え方（3案の比較）：①月の琴＝上に出してはみ出す分は語に被せる（語が読めない）、②前回＝下に出す（指と手に隠れる）、③今回＝上に出して語に被らない高さに縮め、中をスクロール（語も見え、手にも隠れない。短いカードは何も変わらない）。最小の高さ 160px は語の行＋意味の行＋理由2行ほど。本来の高さは「今の高さ＋中身で隠れている分」で測る（DOM の style を直接いじると React が同じ値を書き戻さない）。
検査：`src/tests/wordCardLayout.test.ts`（13件）＋ Playwright（スマホ相当 390×844・タッチ：上半分の語は上に出る／アニメ無し／タップ固定で帯／余白を縦になぞるとスクロールしてもカードは残り語について動く／余白タップで閉じる／最上部の語は下に出る）。実機は未確認。

### 意味の一覧（2026-10-25 ユーザー指示「意味を全部表示、今回の意味を太字」）

- 単語帳の意味の一覧は**必ず全部出す**（1つしか無くても、意味が決まっていない語でも）。太字は**1つだけ**（完全一致があればそれ、無ければ部分一致の最初。月の琴の `senseList` と同じ）。
- それまでは「意味ラベルが無い語」は一覧を出さず「意味」行に ／ 区切りで並べ（全教材で 3,831 語）、「単語帳の意味1つ」の語（75）と、理由が「単語帳の意味とは別に」で始まる語（92）は一覧を伏せていた。
- 「単語帳の意味とは別に」で始まる理由でも、単語帳にその意味が後から入っていれば（2026-10-16 の追加：この世・世の中／思慮／出会う／気持ち・思い）普通の語として扱い、No. の札と太字を出す（`offList` は一致する意味が無いときだけ）。
- 太字が付かないのは、意味ラベルが単語帳のどの意味とも違う語だけ（全教材で 11＋α。例：いみじ「並々でない」／たまふ「尊敬語」／心「心・思い」）。ラベル側の表現の問題で、直すなら教材の meaning か決め手の meaning。
