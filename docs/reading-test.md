## 画面

- 上：ヘッダ（✕＝中断して教材へ戻る／題名／経過時間 mm:ss）と問題番号の丸（済み＝accent の塗り、今＝太い枠）。丸を押すとその問題へ移れる（2026-11-04 ユーザー指示。答えた問題は答えと答え合わせのまま見られる）。「つぎへ」はまだ答えていない次の問題へ進み（後ろに無ければ前に戻って探す）、全部答えると「結果を見る」になる。
- 本文カード：縦書き（`writing-mode: vertical-rl`）。箱の中だけ横にスクロールし、今の問題の傍線部が見えるよう自動で寄せる。冒頭に出典・背景の1行（手書きの `lead`、無ければ `text.source`）。傍線は傍線部の span の `border-right`（縦書きで行の右側に出る）、直前に丸数字。今の問題の傍線部は淡く塗る。**本文は閲覧のみ**（タップの処理を付けない。iOS の縦書きでタップ位置がずれる既知の問題のため）。
- 問題カード：単語クイズと同じ下敷き。札「問N」「語の意味／文法的意味／主語／係り先／内容」、問い文、選択肢（`WordQuizContent` の4択と同じ見た目・○×の付き方）。答えたら `ChatFeedback` で答え合わせ（右＝自分の答え、左＝判定・核イメージ・この箇所の決め手・意味の一覧。先生の台詞は `TEACHER_VOICE_ENABLED` に従う＝今は中立の文）。解説（手書きの `explain`・決め手の要約）は一文ごとに別の吹き出し（2026-11-15 ユーザー指示。`splitSentences`＝「。」「！」「？」で切り、かっこの中では切らない）。「つぎへ →」かタップで次へ。
- 結果：正答数・かかった時間・間違えた問題の一覧（語の意味は単語カード、文法は文法解説へのリンク）・もう一度・教材へ戻る。
- 背景は単語クイズと同じ和柄（`useQuizBackground`／`useQuizBackgroundColor` の設定を共有）。

## 問題の形（自動・手書き共通）

`ReadingQ = { no, kind, sentenceId, span: [開始, 終了], spanText, tokenIds, prompt, choices, answerIndex, explain, lemma?, qid?, target?, grammarRefId? }`。
傍線は**文字範囲**（その文の `originalText` の中の位置。終了は含まない）で持ち、文をまたがない。自動問題はトークンの `start`／`end` から範囲を出す（語に付いた「、」などの句読点は外す）。`tokenIds` は記録用。

## 第1段：自動問題の作り方（捏造しない）

1. **語の意味**（`vocab`）：単語帳（330）に紐づく語。紐づけは読解ページと同じ `resolveVocabKey`（助詞・助動詞は対象外）。
   - この箇所の意味 = 決め手（`public/analysis/<id>.json` の `decider.meaning`）→ 品詞分解の意味（`grammarTag.meaning`。「尊敬語」などの類別だけのものは使わない）。それを `cardSenses`（WordCard と同じ）で単語帳の意味に照らし、当たらない語は出さない。
   - 理由が「単語帳の意味（…）とは別に」で始まる語は出さない。
   - 誤りの選択肢：同じ見出しのほかの意味 → 同じ品詞のほかの語の意味。同義の重なりは `canUseAsDistractor`（`senseEquivalence.ts`）で除き、表示の重なりも除く。表示は辞書形（`senseLabel`＋補助動詞は「補動」）。誤りが2つ未満なら出さない。
   - 傍線は**語だけ**。
2. **文法的意味**（`grammar`）：助動詞。意味 = 決め手の `meaning` → 品詞分解の意味（`grammarMeaningLabel` で略記を戻し、現推→現在推量 などをそろえる）。
   - どの助動詞か = 本文の形と意味から `AUX_TABLE` で決める（「に」＋完了＝ぬ、「に」＋断定＝なり、「ぬ」＋打消＝ず など）。表に無い組は出さない。
   - 誤りの選択肢：その助動詞が取りうる意味（`AUX_TABLE`。出典＝文法道場の単元 `public/grammar/jodoshi-*.json` の意味の表）→ 同じ形のほかの助動詞の意味 → 一般の意味（過去・完了・推量…）。4択。
   - 傍線は**文節**（前の用言＝複合した用言は2語まで、無ければ前の体言など1語＋助動詞の連なり＋尊敬の補助動詞「たまふ」）。連なりの中の1語（意味の数が多い語）を「傍線部②「にけり」の中の助動詞「けり」」のように指して問う。同じ形が2つあれば「2つ目の」と言う。
   - **助動詞が2つ以上続く箇所を優先**し、次に意味が2つ以上ありうる語。
- 1教材あたり最大8問。語の意味と文法を半々（足りない方を他方で埋める）。文法は優先順に、語の意味は文法の傍線と重ならない語から本文全体に散らして選び、本文の前から順に番号を振る。同じ語（見出し・助動詞）は1回。並びは決定的（FNV ハッシュで並べ替え）。
- 語の意味の正解は決め手か意味ラベルが無いと決められないので、単語の理由がまだ無い教材（非公開の多く）は文法だけになる。

## 手書きの問題ファイル

`public/reading-tests/<textId>.json` があれば自動問題の代わりに使う（無い・読めない・有効な問題が0なら自動）。

```json
{ "textId": "...", "title": "...", "lead": "出典・背景の1〜2行",
  "questions": [ { "no": 1, "kind": "vocab|grammar|joshi|subject|kakari|reading|yaku|keigo", "sentenceId": "s3",
    "span": [開始, 終了], "spanText": "傍線部の文字列（検査用）", "prompt": "問い文",
    "choices": ["..", ".."], "answerIndex": 1, "explain": "解説（1〜3文）" } ] }
```

- `span` はその文の `originalText` の中の文字位置（終了は含まない）。`spanText` が本文の該当範囲と一致しない問題、文・範囲・kind・選択肢（2つ以上・重複なし）・`answerIndex` が正しくない問題は読み込み時に捨てて `console.warn`。
- 番号は捨てた分を詰めて振り直す（問い文の先頭の「傍線部①」も合わせる）。`explain` は答え合わせの吹き出しに出す。
- 傍線の長さは語だけ・句・一文が混ざるようにする（自動問題は語＝語の意味、文節＝文法）。
- 火鼠の皮衣（5954a8d9eb）・龍の首の玉（cd8147e868）は別の担当が書く予定。→ 2026-11-15 火鼠の皮衣に助動詞10・単語5・助詞3を足して33問（vault の 4-4 も同じ）。

## 分類で分けて出す（2026-11-15、ユーザー指示）

問題が増えて1回が長くなったので、問題の種類（`kind`）で分け、始める前に選ばせる。同日、ユーザー指示で助動詞と助詞・係り結びも分けた。

| 分類（`?g=`） | 入る種類 |
|---|---|
| 助動詞（`aux`） | grammar・keigo |
| 助詞・係り結び（`joshi`） | joshi・kakari |
| 助動詞・助詞（`grammar`） | 上の2つを合わせたもの。助動詞と助詞・係り結びのどちらかが3問未満の教材でだけ出す |
| 単語（`vocab`） | vocab |
| 訳・読解（`read`） | yaku・reading・subject |

- 種類 `joshi`（札「助詞」）＝助詞だけを問う文法の問題（2026-11-15 新設）。助詞と助動詞を組で問う問題（「接続助詞・過去の助動詞」など）は `grammar` のまま。既存の4教材6問を `joshi` にした（火鼠3・2e45c61a81「何そ」・faa890f809「伊豆の海や」・3d0d7bf6ee「なむ」）。vault の 4-4 の札は〔文法〕のまま。

- 3問に満たない分類はボタンを出さない（`MIN_GROUP_QUESTIONS`）。選べる分類が2つ未満の教材は、選ぶ画面を出さずに全部を出す。選ぶ画面の下に「全部まとめて解く」（`?g=all`）。
- 選んだ分類の問題は本文の順のまま、番号と問い文の「傍線部①」を1から振り直す（`selectGroup`。元の番号は `srcNo` で、記録の `targetId` に使う）。分類は URL に持つので「もう一度」は同じ分類、結果画面の「ほかの分類へ」で選ぶ画面へ戻る。
- 純関数 = `src/lib/kobun/readingTest.ts` の `READING_GROUPS`・`availableGroups`・`selectGroup`、画面 = `src/pages/ReadingTest.tsx`、テスト = `src/tests/readingTest.test.ts`。
- 火鼠の皮衣は 33問（助動詞12・助詞・係り結び5・単語8・訳・読解8）。ほかの手書き問題の教材は助動詞・助詞が合わせた1つになり、単語が2問程度なので多くは2つのボタンで、単語の問いは「全部」でだけ出る（選ぶ画面の出ない教材は3つ）。
- 丸数字は ㊿ まで（2026-11-15。それまでは ⑳ までで、21問目以降は「(21)」と出ていた）。

## 第2段の予定

kokugo-vault の教材 MD に、主語（`subject`）・係り先（`kakari`）・内容（`reading`）の選択式問題を書き起こし、上の手書きの形で `public/reading-tests/` に出す（源流は vault、配信はアプリ）。自動では作らない（正解が品詞分解のデータから決まらないため）。書き起こしでは、傍線を句・一文にも引き、誤りの選択肢は本文の別の人物・別の箇所から取る。
