# 苦手・未定着の復習と文法の段階的補助（2026-09-19）

## 実装

- 単語ホームを余白・見出し・学習開始ボタン・苦手復習の順に再構成。既存テーマに対応し、375pxでも横にはみ出さない。
- `word_stats` の誤答率40%以上（初回から）に加え、`srs_state.box=1` の再学習対象を苦手として抽出。累計正答率が高い語の直近の忘却も回収する。
- 期限前の正解ではSRSの箱と期限を維持する。期限を迎えた正解で昇格、不正解は箱1へ。箱2・3を同日の正解数だけで得意扱いしない。
- 単語ホームの復習・ウォームアップ・苦手抽出は読み込んだ単語qidで絞る。文法のqidが今日の単語枠を消費しない。
- 文法は選択したレベルから最大8問。既存DBの問題別成績を出題に反映する。問題文の対象語は示すが、意味決定の手がかりの強調は回答後。
- 最初の本問をすべて解いてから、振り返り（接続／活用・形／意味・文脈／不明）に対応する同単元の下位問題を出し、元の問題に戻る。
- 補助にも失敗すればさらに下位へ進める。ただし補助・再挑戦の追加は合計6問まで。同じ補助を繰り返し追加しない。下位問題がないときはリファレンスへ案内。
- 本問の初回得点と補助・再挑戦の得点を分ける。単元到達度へ送るのは本問だけ。問題ごとの正誤・復習期限は従来のDBへ保存する。
- 文法セッションでは保存完了を待って次へ進む。保存失敗は表示し、二重クリックも防ぐ。

## 判定の意味と制約

下位問題は既存の単元・問題種別・難度と正誤履歴から選ぶ。教師が検証した前提知識グラフではなく、誤答原因を断定する診断ではない。該当する既存問題がなければ生成しない。

自力回答と補助回答の内訳、および本人の振り返りはセッション内の情報。既存DBの `word_stats` / `srs_state` には回答役割や振り返り理由の列はなく、問題別の集計・復習状態を保存する。原因の推移や補助依存度を端末間で長期分析する場合は、回答イベント（問題ID、初回／補助／再挑戦、振り返り、正誤、時刻）を別途保存するDB拡張が必要。

`grammar_topic_progress.mastery_pct` は従来の自己ベストによる到達実績であり、現在の保持率を意味しない。成績表示は今回の本問クリアと表現し、長期保持はSRSで再確認する。既存qid・教材内容・DBスキーマは変更していない。
