# Phase B バッチ設計 — AI増補の運用書（2026-07-02）

> 上位設計は `vocab-overhaul-design.md`。本書は Phase B（核イメージ・決め手・用例紐付け・trap・検品）を
> 8GB機で安全に回すための実務設計。例文集コーパス（/kobun-reibun-corpus）の軽量運用を踏襲する。

## 共通運用

- **全てインライン逐次**。サブエージェント・Workflow は使わない（Bun クラッシュ回避）
- 1バッチ = 1応答で完結する量。中断・クラッシュしても `data/enrich/state.json` から再開
- 中間成果は `data/enrich/` に JSON で蓄積 → apply スクリプトで**冪等マージ**（何度流しても同じ）
- バッチごとに検品用 MD（`docs/enrich-review.md`）へ追記 → 人間はスポットチェック
- **捏造ガード**: 新規例文は作らない（既存例文の解釈・分類・注釈のみ）。核イメージは語源の断定を避け
  「覚えるためのイメージ」として書く。訳の誤りは**指摘のみ**（修正は人間判断）

## B1: 核イメージ＋決め手＋訳検品 — 23バッチ

単位は lemma。1バッチの出力 = `data/enrich/core-<連番>.json`。

| 回 | 対象 | バッチ数 |
|---|---|---|
| B1-a | 多義語231語（意味数の多い順）× 15語/バッチ | 16 |
| B1-b | 単義語134語（核イメージ＋trap判定のみ、決め手は簡略）× 20語/バッチ | 7 |

出力スキーマ（1語分）:

```jsonc
{
  "lemma": "おどろく",
  "senseCore": "ハッとする（外の刺激で意識が切り替わる）",   // ≤20字目安
  "trap": { "modern": "びっくりする", "note": "現代語訳「驚く」は原則誤り" },  // 古今異義語のみ
  "senses": [
    { "qid": "1-1", "senseNorm": "気づく",                    // 表記正規化(終止形)
      "decider": {
        "clue": "風の音・秋来ぬ など知覚のきっかけ。睡眠場面でない",  // 共起・場面の手がかり
        "rule": "五感への刺激で意識が向く文脈なら〈気づく〉"          // 判別1行
      } },
    { "qid": "1-2", "senseNorm": "目を覚ます",
      "decider": {
        "clue": "寝たるに・夢・暁・襲はるる心地 など睡眠の場面",
        "rule": "眠っている状況が前提なら〈目を覚ます〉"
      } }
  ],
  "transIssues": []   // 例文と訳の不整合を発見したら {qid, exIdx, issue} で記録(修正しない)
}
```

- 入力は kobunQ.v2 の senses＋例文（用例バンクの実文も文脈参考にする）
- **訳検品（旧B4）はここに統合**：同じ語の例文を読む作業なので同一バッチで拾うのが最効率
- trap 判定も全語で行い、B1 完了後にスクリプトで `modern_traps.json` 拡充案に集約（旧B3も統合）

## B2: 用例 sense 紐付け — 約43バッチ

単位は lemma グループ（計75件前後/バッチ）。出力 = `data/enrich/bind-<連番>.jsonl`。

```jsonc
{ "lemma": "あやし", "key": "<正規化文キー>", "verdict": "23-1" }
// verdict: qid ＝ その意味に紐付け
//          "unknown" ＝ 文脈不足で判定不能（unboundのまま）
//          "reject"  ＝ 別語の誤混入（例: baseForm「よる」が動詞でなく名詞「夜」だった）→バンクから除外
```

- 対象は**全 3,203件**（2026-07-02 ユーザー決定: 超頻出8語も AI で紐付け）
- 順序: 内容語 226語 / 1,501件（kobunQ 番号順）→ 超頻出8語 / 1,702件（たまふ→なる→…）
- 超頻出8語は本動詞/補助動詞の別が sense を決めるため、snippet の前接語を判定材料に明示する
- 適用は `build-example-bank.py` に bindings 読込を追加して再生成（バンクは常に再現可能に保つ）

## apply スクリプト（B1バッチ1と同時に作成）

| script | 役割 |
|---|---|
| `scripts/apply-enrich.py` | core-*.json を kobunQ.v2.json にマージ（冪等）。transIssues を docs/enrich-review.md に集約 |
| `scripts/build-example-bank.py`（改修） | data/enrich/bind-*.jsonl を読み、senseId 反映・reject 除外して再生成 |
| `scripts/collect-traps.py` | core-*.json の trap を modern_traps.json 拡充案に集約 |
