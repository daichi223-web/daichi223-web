# 識別の分解（理解に必要なもの）

2026-11-16。`docs/grammar-lessons/decomposition.md` の A（動詞）と同じ形で、識別の7単元を分解した。

- 識別の手順は、どの語でも同じ4つ。1つの手順＝1つの要素（S-1〜S-4）。
  1. 直前の形（接続）を見る
  2. 直後の語を見る
  3. 取り除いて、残りを見る（文が成り立つか・前が言葉として残るか）
  4. 意味で入れ替える（訳を当てて通るか）
- 語ごとの単元では、「候補（正体の一覧）」を1つの要素にし、そのあとに「その語で使う手順」を1つずつ要素にした。
  - 手順を使わない語では、その手順の要素を作っていない（例：「し」は手順4を作らない）。
  - 1単元の要素は5つまで（台本の parts は5つまで）。
- 記号は A と同じ。【前提】・【新】・〔例〕・〔問〕（はじめが正解）。
- 例は、作品名を付けない短い形（咲かぬ・咲きぬ）か、教材の本文・ドリルの例文をそのまま写したもの。本文から写したものは「本文：」と書いた。
- 躓きは、本番の回答（`reports/drill-stumbles-2026-11-15.json`）とドリルの誤答の選択肢から書いた。実データがあるのは「に」（124件・6人）と「なむ」（65件・4人）だけ。ほかは「実データ少」。

## S. 識別の手順（全単元に共通）

### S-0 識別とは【新】
- 同じ形（同じ字）の語の、正体を見分けること。正体＝品詞や、どの助動詞か。
- 正体が変わると、訳が変わる。
- 〔例〕咲か**ぬ**花（打消）／花咲き**ぬ**（完了）／死**ぬ**（ナ変動詞の一部）
- 〔例〕京**に**着く（格助詞）／暮れ**に**けり（完了「ぬ」）
- 〔問〕「咲かぬ」と「咲きぬ」の「ぬ」は？（別の語／同じ語／同じ語で形だけがちがう）
- 躓き：字が同じなので同じ語だと思い、訳の感じで正体を決める（教科書的な紛れ。実データ少）。

### S-1 手順1：直前の形（接続）を見る【新】
- 助動詞は、前の語を何形にするかが決まっている（C-1）。だから、直前の語の活用形で候補がしぼれる。
- 直前が体言か、活用する語かも見る。
- 〔例〕咲か（未然形）＋ぬ → 打消「ず」。咲き（連用形）＋ぬ → 完了「ぬ」。
- 〔例〕落つる（連体形）＋なり → 断定。落つ（終止形）＋なり → 伝聞推定。
- 〔例〕将軍（体言）＋たり → 断定。咲き（連用形）＋たり → 完了・存続。
- 〔問〕「咲かぬ花」の「咲か」は何形？（未然形／連用形／連体形／終止形）
- 躓き：
  - 後ろの体言（花）につられて、直前の語を連体形と答える。見るのは「ぬ」の前の語の形。
  - 直前の形で決まらない語がある（A-7：見え・受け・見は未然＝連用、泣くは終止＝連体）。→ 手順2・4へ進む。
  - 実データ少（この手順だけを問う問いは無い）。

### S-2 手順2：直後の語を見る【新】
- 直後の語にも、前を何形にするかの決まりがある。だから、後ろの語から識別する語の活用形が決まる。
- 間に係助詞（や・こそ・は・も）が入ることがある。その先の語まで見る。
- 〔例〕暮れ**に**けり：「けり」は連用形に付く → 「に」は連用形 → 完了「ぬ」の連用形。
- 〔例〕夢**に**やあらむ：「や」の先に「あら（あり）」→ 断定「なり」の連用形。
- 〔例〕見**し**人：後ろが体言 → 「し」は連体形 → 過去「き」。
- 〔問〕「夢にやあらむ」の「に」の正体を決める、後ろの手がかりは？（あら／や／む／夢）
- 躓き：「や」で止まって、その先の「あら」を見ない（根拠：問「夢にやあらむ」で初回誤答3/3人、「格助詞」2・「完了「ぬ」の連用形」2）。

### S-3 手順3：取り除いて、残りを見る【新】
- その語を取り除いて、残りを見る。
- 残りが文として成り立つ → 強めるだけの助詞（係助詞「なむ」・副助詞「し」）。結びの連体形は終止形に戻して確かめる。
- 前の部分が言葉として残らない → 語の一部（動詞・形容詞・形容動詞の活用語尾、副詞の一部）。
- 〔例〕雨なむ降りける → 雨降りけり（成り立つ → 係助詞）。名にし負はば → 名に負はば（成り立つ → 副助詞）。
- 〔例〕死ぬ → 「死」、涙流れて → 「流」、静かに → 「静か」（言葉として残らない → 語の一部）。
- 〔問〕「なむ」を取り除いて文が成り立つのは？（雨なむ降りける／花咲かなむ／花咲きなむ）
- 躓き：
  - 結びを戻さず「雨降りける」として迷う。
  - 語の一部（静かに・流れ）を、助詞・助動詞として切り出す（根拠：ドリルの誤答の選択肢「格助詞」「受身「る」の連用形」）。
  - 係助詞「なむ」の問い2つ（namu-w10・w12）は初回誤答0/4人。この手順は使えている。

### S-4 手順4：意味で入れ替える【新】
- 残った候補の訳を当てはめて、文の意味が通るかで決める。形で決まらないときの決め手になる。
- 訳の感じから先に決めない。手順1〜3で候補をしぼってから使う。
- 〔例〕京に着きぬ：「京であって着いた」は通らない → 断定ではない → 格助詞（場所）。
- 〔例〕（隣の部屋で）人泣くなり：「泣く」は終止形も連体形も同じ。泣く声を聞いている場面なので「泣く声が聞こえる」→ 伝聞推定。
- 〔問〕「京に着きぬ」の「に」を「であって」に入れ替えると？（通らないので断定ではない／通るので断定／入れ替えでは決まらない）
- 躓き：体言の後ろの「に」を、入れ替えずに断定と答える（根拠：問「京に着きぬ」で「断定「なり」の連用形」2、4人中）。

## S-1x. 「に」（shikibetsu-ni）

### S-10 6つの「に」（候補）【新】
- 「に」は、2つの助動詞の形でもある。完了「ぬ」の連用形（な・に・ぬ・ぬる・ぬれ・ね）と、断定「なり」の連用形。
- ほかに、格助詞・接続助詞・形容動詞の語尾・副詞の一部がある。
- 〔例〕散り**に**き の「に」＝ 散り**ぬ** の「ぬ」と同じ語（完了）／夢**に**やあらむ（断定）
- 〔例〕京**に**着く（格助詞）・待つ**に**、人来ず（接続助詞）・静か**に**眠る（形容動詞）・げ**に**（副詞）
- 〔問〕「散りにき」の「に」と同じ語を含むのは？（散りぬ／散るなり／散れり／散らず）
- 躓き：「に」が完了「ぬ」の形の1つだとつながっていない。字の似た「なり」や、同じ完了の「り」を選ぶ（根拠：この問いで初回誤答3/4人、「散るなり」2・「散れり」1）。

### S-11 「に」の直前を見る（手順1）【新】
- 連用形＋に → 完了「ぬ」の候補。
- 体言＋に → 断定か格助詞。連体形＋に → 断定か接続助詞。直前だけで決まらないときは、手順2・4へ。
- 〔例〕散り（連用形）＋に＋けり ／ 見る（連体形）＋に、涙落つ
- 〔例〕京（体言）＋に ／ 起くる（連体形）＋に
- 〔問〕「散りにけり」の「散り」は何形？（連用形／未然形／連体形）
- 躓き：
  - 直前が体言だと、すぐ格助詞と決める（根拠：問「夢にやあらむ」で「格助詞」2）。
  - 直前が助詞のこともある（本文：「この言葉、何と【に】は《なけれ》ども…」＝断定）。直前だけで決めない。

### S-12 「に」の直後を見る（手順2）【新】
- 直後に「き・けり・たり」→ 完了「ぬ」の連用形。
- 直後に「あり・侍り・候ふ」→ 断定「なり」の連用形。間に や・か・こそ・は・も が入ることが多い。
- 〔例〕暮れ**に**けり（完了）／夢**に**やあらむ・これは夢**に**こそあれ（断定）
- 〔例〕本文：「その夜御扇開き見るに、筆の歩み常人の文柄【に】も《あら》ず。」（「も」をはさんで「あら」→ 断定）
- 〔問〕「夢にやあらむ」の「に」の正体は？（断定「なり」の連用形／格助詞／完了「ぬ」の連用形）
- 躓き：根拠：問「夢にやあらむ」で初回誤答3/3人（「格助詞」2・「完了「ぬ」の連用形」2）。問「不義をよしとする【に】は《あら》ず」で「接続助詞」1・「完了」1。

### S-13 「に」を切り離す（手順3）【新】
- 「に」を切ると、前が言葉として残らない → 語の一部。
- 「静かに」「あはれに」は形容動詞の連用形の語尾（静かなり・あはれなり と言い切れる）。「げに」「さらに」「つひに」は副詞の一部。
- 〔例〕静か｜に眠る → 「静かなり」の連用形
- 〔例〕げ｜に → 「げ」だけでは言葉にならない
- 〔問〕「静かに眠る」の「に」の正体は？（ナリ活用形容動詞の語尾／格助詞／断定「なり」の連用形）
- 躓き：問「静かに眠る」で「格助詞」1（4人中）。問「あはれに思ふ／夕暮れに思ふ」は初回誤答0/4人。

### S-14 「に」を訳で入れ替える（手順4）【新】
- 「〜であって」「〜で」と入れ替えて通れば、断定。
- 通らないとき、体言の後ろなら格助詞（場所・時・相手の「〜に」）、連体形の後ろで文が先へ続けば接続助詞（「〜と」「〜のに」「〜ので」）。
- 〔例〕夢にやあらむ → 夢であろうか（断定）／京に着きぬ → 「京であって」は通らない（格助詞）
- 〔例〕待つに、人来ず → 待つのに、人が来ない（接続助詞）
- 〔問〕「待つに、人来ず」の「に」の正体は？（接続助詞／格助詞／断定「なり」の連用形）
- 躓き：根拠：問「京に着きぬ」で「断定」2、問「待つに、人来ず」で「断定」1・「格助詞」1。
  - 補足：連体形＋「に」が格助詞か接続助詞かは、学説で分かれる箇所がある（教材の識別レイヤー `shikibetsuYure.ts`）。台本ではドリルどおり「連体形の後ろで文が続く＝接続助詞」とだけ教える。

## S-2x. 「ぬ」「ね」（shikibetsu-nu-ne）

### S-20 3つの「ぬ」と2つの「ね」（候補）【新】
- 打消「ず」：連体形「ぬ」・已然形「ね」。完了「ぬ」：終止形「ぬ」・命令形「ね」（ほかに な・に・ぬる・ぬれ）。ナ変動詞「死ぬ・往ぬ」の語尾。
- 「ぬる」「ぬれ」は完了にしか無い形。
- 〔例〕咲か**ぬ**花（打消・連体形）／花咲き**ぬ**（完了・終止形）／死**ぬ**（ナ変）
- 〔例〕行か**ね**ば（打消・已然形）／とく行き**ね**（完了の命令形）
- 〔問〕「ぬる」「ぬれ」の形があるのは？（完了「ぬ」だけ／打消「ず」だけ／どちらにもある）
- 躓き：「ね」が打消の已然形にもなることを知らない（教科書的な紛れ。実データ少）。

### S-21 「ぬ・ね」の直前を見る（手順1）【新】
- 未然形＋ぬ・ね → 打消「ず」。連用形＋ぬ・ね → 完了「ぬ」。
- 四段動詞なら、前の1字がア段なら打消、イ段なら完了。
- 〔例〕帰ら**ぬ**（ら＝ア段 → 打消）／帰り**ぬ**（り＝イ段 → 完了）
- 〔例〕知ら**ぬ**人（打消）／風立ち**ぬ**（完了）
- 〔問〕「家に帰りぬ」と「家に帰らぬ」。「帰った」はどちら？（帰りぬ／帰らぬ／両方）
- 躓き：今の言葉の「知らぬ」（打消）の感覚と、「〜ぬ＝完了」の思い込みの両方がある（根拠：ドリルの対比問「帰りぬ／帰らぬ」、誤答の選択肢「完了「ぬ」の終止形」「打消「ず」の連体形」。実データ少）。

### S-22 「ぬ・ね」の直後と位置を見る（手順2）【新】
- 直前で決まらない語（見え・受け・見）は、後ろの語と位置で活用形を決める。
- 体言の前の「ぬ」→ 連体形 → 打消（完了の連体形なら「ぬる」）。「ね」＋ば・ども → 已然形 → 打消（完了の已然形は「ぬれ」）。
- 文末で言い切る「ぬ」→ 終止形 → 完了。ただし ぞ・なむ・や・か の結びなら連体形。
- 〔例〕見え**ぬ**山（打消）／月見**ね**ば（打消）
- 〔例〕本文：「日も暮れぬ。」（「暮れ」は下二段。文末で言い切る → 完了の終止形）／花や咲か**ぬ**（「や」の結び → 連体形 → 打消）
- 〔問〕「見えぬ山」の「ぬ」の正体は？（打消「ず」の連体形／完了「ぬ」の終止形／ナ変動詞の語尾）
- 躓き：
  - 未然形と連用形が同じ動詞では手順1が使えないことに気づかない（根拠：問「見えぬ山」「月見ねば」）。
  - 文末の「ぬ」を、係助詞を見ずに完了と決める（根拠：問 nu-ne-09「文末なのに打消の「ぬ」。なぜ？」）。
  - 「日も」の「も」は係助詞だが、連体形の結びを作らない。実データ少。

### S-23 「ぬ・ね」を切り離す（手順3）【新】
- 「ぬ」「ね」を切ると「死」「往」だけになる → ナ変動詞の語尾。ナ変は「死ぬ」「往ぬ（去ぬ）」の2語だけ（A-6）。
- 〔例〕死**ぬ**／はや往**ね**（「往ぬ」の命令形）
- 〔例〕とく行き**ね**：切っても「行き」が動詞として残る → 「ね」は完了「ぬ」の命令形
- 〔問〕「はや往ね」の「ね」の正体は？（ナ変動詞の命令形語尾／完了「ぬ」の命令形／打消「ず」の已然形）
- 躓き：「死ぬ」の「ぬ」を完了と取る（根拠：ドリルの誤答の選択肢「完了「ぬ」」「完了「ぬ」の命令形」。実データ少）。

### S-24 「ぬ」を訳で入れ替える（手順4）【新】
- 打消なら「〜ない」、完了なら「〜た・〜てしまう」と入れ替えて、文に合うか確かめる。
- 完了「ぬ」の下に む・べし・まし が来るときや、命令形「ね」のときは、強意「きっと〜」になる（C-2・jodoshi-nu）。正体は完了の助動詞「ぬ」のまま。
- 〔例〕見えぬ山 → 見えない山（通る）
- 〔例〕花散りぬべし → きっと散ってしまうだろう（強意）
- 〔問〕「花散りぬべし」の「ぬ」の意味は？（強意／打消／完了）
- 躓き：「ぬ」＝「〜た」とだけ覚えていて、下の「べし」を見ない（教科書的な紛れ。実データ少）。
  - 2026-11-16 の決定：つ・ぬ は む・べし・まし などが続くときと命令形で強意。原因推量の「らむ」と「けむ」の前は完了。

## S-3x. 「なむ」（shikibetsu-namu）

### S-30 4つの「なむ」（候補）【新】
- 強意＋推量（完了「ぬ」の未然形「な」＋「む」）、願望の終助詞、係助詞、ナ変動詞の未然形の語尾「な」＋「む」。
- 1語の「なむ」は、願望の終助詞と係助詞だけ。ほかの2つは「な／む」の2語。
- 〔例〕花咲き**なむ**（強意＋推量）／花咲か**なむ**（願望）
- 〔例〕これ**なむ**都鳥（係助詞）／死**なむ**（ナ変＋む）
- 〔問〕強意＋推量の「なむ」の「な」は何？（完了「ぬ」の未然形／打消「ず」の未然形／ナ変動詞の語尾）
- 躓き：「なむ」を1語と見て、「死なむ」も強意＋推量や願望と答える（根拠：ドリルの誤答の選択肢。実データ少）。

### S-31 「なむ」の直前を見る（手順1）【新】
- 連用形＋なむ → 強意＋推量。未然形＋なむ → 願望の終助詞。体言・助詞＋なむ → 係助詞。
- 四段動詞は、前の1字（り／ら）で意味が逆になる。
- 〔例〕帰り**なむ**（り＝イ段・連用形）／帰ら**なむ**（ら＝ア段・未然形）
- 〔例〕あり**なむ**（連用形）／あら**なむ**（未然形）
- 〔問〕「花咲かなむ」の「なむ」の正体は？（願望の終助詞／強意「ぬ」＋推量「む」／係助詞）
- 躓き：前の1字の見分けがあいまい（根拠：問「日暮れて鳥は山へ《帰り》【なむ】」で「帰ってほしい」1、4人中）。

### S-32 「なむ」の後ろ（文末の結び）を見る（手順2）【新】
- 係助詞「なむ」があると、文末は連体形で結ぶ。
- 願望の終助詞「なむ」は、文の終わりに来る。
- 〔例〕雁なむ北へ帰り**ける**（「ける」は「けり」の連体形）
- 〔例〕本文：「年ごとの桜の花盛りには、その宮へなむおはしましける。」
- 〔問〕係助詞「なむ」がある文で、文末は何形になる？（連体形／終止形／已然形）
- 躓き：連体形の結びと、「こそ」の已然形の結びを混ぜる（教科書的な紛れ）。問 namu-w12（正体と結びの組）は初回誤答0/4人。

### S-33 「なむ」を取り除いて、残りを見る（手順3）【新】
- 「なむ」を取って文が成り立つ → 係助詞。結びの連体形は終止形に戻す。
- 「な」を切ると前が言葉として残らない（死・往）→ ナ変動詞の語尾＋「む」。
- 〔例〕雨なむ降りける → 雨降りけり（係助詞）
- 〔例〕死なむ → 「死」だけ（ナ変「死ぬ」の未然形「死な」＋む）
- 〔問〕「往なむ」の「なむ」の正体は？（ナ変未然形の語尾＋推量「む」／強意「ぬ」＋推量「む」／願望の終助詞）
- 躓き：「死なむ」「往なむ」の「な」を完了「ぬ」と取る（根拠：ドリルの誤答の選択肢「強意「ぬ」＋推量「む」」。実データ少）。

### S-34 「なむ」を訳で入れ替える（手順4）【新】
- 強意＋推量＝「きっと〜だろう」、願望＝「〜してほしい」、係助詞＝訳さない。
- 〔例〕帰りなむ → きっと帰ってしまうだろう／帰らなむ → 帰ってほしい
- 〔例〕ありなむ → きっとあるだろう／あらなむ → あってほしい
- 〔問〕「日暮れて鳥は山へ帰りなむ」の「なむ」の訳は？（きっと帰ってしまうだろう／帰ってほしい／帰るのだ（強調））
- 躓き：根拠：この問い（namu-w05）で「帰ってほしい」1（4人中）。

## S-4x. 「る」「れ」（shikibetsu-ru-re）

### S-40 「る」「れ」の候補【新】
- 助動詞「る」（受身・尊敬・可能・自発）：れ・れ・る・るる・るれ・れよ。
- 完了・存続「り」：連体形「る」、已然形・命令形「れ」。
- 動詞の一部（忘る・流れ・枯れ）。
- 〔例〕知ら**るる**人（る）／書け**る**文（り）／忘**る**（動詞）
- 〔例〕言は**れ**けり（る）／立て**れ**ば（り）／流**れ**て（動詞）
- 〔問〕完了・存続「り」の連体形は？（る／るる／れ）
- 躓き：「る」「れ」といえば受身と思う（教科書的な紛れ。実データ少）。

### S-41 「る・れ」を切り離す（手順3。この語では先に行う）【新】
- 「る・れ」を切って、前が動詞として残るか見る。残らなければ動詞の一部。
- 〔例〕流｜れて → 「流」では動詞にならない（「流る」の連用形）／枯｜れたる木
- 〔例〕言は｜れけり → 「言は」は「言ふ」の未然形として残る → 助動詞
- 〔問〕「涙流れて」の「れ」の正体は？（動詞の一部／受身「る」の連用形／完了「り」の已然形）
- 躓き：「流れ」の「が」はア段なので、手順1（ア段＋れ＝る）を先に当てると受身に見える（根拠：問「涙流れて」「枯れたる木」の誤答の選択肢「受身「る」の連用形」）。そのため、この語だけ手順3を先にする。

### S-42 「る・れ」の直前の段を見る（手順1）【新】
- ア段（未然形）＋る・れ → 助動詞「る」。
- エ段＋る・れ → 完了・存続「り」。「り」はサ変の未然形と四段の已然形に付く（サ未四已）。
- 〔例〕知ら**るる**人・言は**れ**けり（ア段）
- 〔例〕書け**る**文・門に立て**れ**ば（エ段）
- 〔問〕「書ける文」の「る」の正体は？（完了・存続「り」の連体形／受身「る」の連体形／動詞の一部）
- 躓き：エ段＋る を受身と取る（根拠：問「書ける文」「門に立てれば」の誤答の選択肢。実データ少）。

### S-43 「る・れ」を訳で入れ替える（手順4）【新】
- 「り」なら「〜ている・〜てある」（存続）か「〜た」（完了）。「る」なら「〜れる・〜られる」など。
- 〔例〕書ける文 → 書いてある手紙（存続）／門に立てれば → 門に立っているので（存続）
- 〔例〕人に言はれけり → 人に言われた（受身）
- 〔問〕「門に立てれば」の訳は？（門に立っているので／門に立たれるので／門に立つならば）
- 躓き：存続の「り」を「〜てしまった」と訳す（訳の決まり `kobun-hango-chokuyaku`。実データ少）。

（「る」と決まったあとの4つの意味＝尊敬・自発・可能・受身は、jodoshi-ru の要素（C-2）を前提として使う。この単元のドリル08・09が問うので、台本では短い part を置く。）

## S-5x. 「なり」（shikibetsu-nari）

### S-50 4つの「なり」（候補）【新】
- 助動詞が2つ：断定「なり」・伝聞推定「なり」。
- ほかに、形容動詞の語尾と、動詞「成る」。
- 〔例〕これは竹**なり**（断定）／奥に人あん**なり**（伝聞推定）
- 〔例〕静か**なり**（形容動詞）／大人に**なり**ぬ（動詞「成る」）
- 〔問〕「なり」の正体に入らないものは？（打消／断定／伝聞推定／動詞「成る」）
- 躓き：助動詞の「なり」が2つあることがあいまい（教科書的な紛れ。実データ少）。

### S-51 「なり」の直前を見る（手順1）【新】
- 体言・連体形＋なり → 断定。終止形＋なり → 伝聞推定。格助詞「に」＋なり → 動詞「成る」（〜になる）。
- 終止形と連体形の形がちがう語（上二段・下二段・サ変 など）なら、ここで決まる。
- 〔例〕落つる**なり**（連体形 → 断定）／落つ**なり**（終止形 → 伝聞推定）
- 〔例〕春**なれ**ば（体言 → 断定）／春に**なれ**ば（「に」→ 動詞「成る」）
- 〔問〕「落つなり」と「落つるなり」。断定はどちら？（落つるなり／落つなり／両方）
- 躓き：「春なれば」と「春になれば」の区別（根拠：問 nari-06）。実データ少。

### S-52 撥音便「あんなり」を見る（手順1）【新】
- ラ変型の語（あり など）に伝聞推定が付くと、「あんなり・なんなり・ざんなり」になりやすい。
- 「ん」を書かず「あなり」とも書く（onbin）。
- 〔例〕奥に人あん**なり**
- 〔例〕本文：「龍の首に、五色に光る玉あなり。」（訳：五色に光る玉があるそうだ）
- 〔問〕「奥に人あんなり」の「なり」の正体は？（伝聞推定「なり」／断定「なり」／動詞「成る」）
- 躓き：撥音便を伝聞推定の目印として知らない（根拠：問 nari-07「奥に人あんなり」。実データ少）。

### S-53 「なり」までで1語か（手順3）【新】
- 「なり」を切って、前が名詞として使えなければ、形容動詞の語尾。「〜げなり」「〜かなり」の形が多い。
- 名詞なら「〜が」と言える（竹が）。「静か」は「静かが」とは言えない。
- 〔例〕静か**なり**・清げ**なり**（形容動詞）
- 〔例〕これは竹**なり**（「竹が」と言える → 名詞＋断定）
- 〔問〕「清げなり」の「なり」の正体は？（ナリ活用形容動詞の語尾／断定「なり」／伝聞推定「なり」）
- 躓き：形容動詞を体言＋断定と取る（根拠：問 nari-08 の誤答の選択肢「断定「なり」」。実データ少）。

### S-54 「なり」を訳で入れ替える（手順4）【新】
- 四段動詞のように終止形と連体形が同じ形の語では、手順1で決まらない（A-7）。
- 音・声を聞いて言っている文なら、伝聞推定「〜が聞こえる」「〜ようだ」。そうでなければ断定「〜である」で通るか見る。
- 〔例〕（隣の部屋で）人泣く**なり** → 泣く声が聞こえる（伝聞推定）
- 〔例〕これは竹**なり** → 竹である（断定）
- 〔問〕「（隣の部屋で）人泣くなり」の「なり」の正体は？（伝聞推定「なり」／断定「なり」／ナリ活用形容動詞の語尾）
- 躓き：音の場面という決め手を使えない（根拠：問 nari-09、本文の問 c10「人も《とふ》【なり】」。実データ少）。

## S-6x. 「し」（shikibetsu-shi）

### S-60 4つの「し」（候補）【新】
- 過去「き」の連体形、サ変「す」の連用形、副助詞（強意）、形容詞の語尾。
- 〔例〕昔見**し**人（過去）／物語など**し**けり（サ変）
- 〔例〕名に**し**負はば（副助詞）／うれ**し**（形容詞）
- 〔問〕過去「き」の連体形はどれ？（し／き／しか）
- 躓き：「〜して」に見えると、すぐサ変と思う（根拠：問 shi-w11 の解説「サ変「して」と早合点しない」。実データ少）。

### S-61 「し」の直後を見る（手順2）【新】
- し＋体言 → 過去「き」の連体形。
- し＋て・けり・たり → サ変「す」の連用形（て・けり・たり は連用形に付く）。
- 〔例〕見**し**夢・あり**し**日（後ろが体言）
- 〔例〕物語**し**けり・物語など**し**て笑ふ（後ろが けり・て）
- 〔問〕「昔見【し】人に、物語など【し】て別れにき」の前の「し」と後の「し」は？（前＝過去「き」連体形／後＝サ変連用形、前＝サ変連用形／後＝過去「き」連体形、前＝過去「き」連体形／後＝副助詞）
- 躓き：1文に2つの「し」があると混ぜる（根拠：問 shi-w12。実データ少）。

### S-62 過去「き」の直前の形（手順1）【新】
- 過去「き」は連用形に付く（見し・ありし・出でし）。
- ただし、カ変「来」には「こし」、サ変「す」には未然形「せ」に付いて「せし」。
- 「にし」は、完了「ぬ」の連用形「に」＋過去「し」。
- 〔例〕来（こ）**し**方／せ**し**事（した事）
- 〔例〕過ぎに**し**年
- 〔問〕「せし事」の「せ」と「し」は？（サ変未然形「せ」＋過去「き」連体形「し」／サ変連用形「せ」＋副助詞「し」／過去「き」未然形＋サ変「し」）
- 躓き：「せし」を「サ変＋副助詞」と分ける、「しし事」と作る（根拠：問 shi-08・w05 の誤答の選択肢。実データ少）。

### S-63 「し」を取り除いて、残りを見る（手順3）【新】
- 「し」を取って意味が通る → 副助詞（強意）。「しも」の形も多い。
- 「し」までで1語なら、形容詞の語尾。「恋しく」は後ろの「く」まで含めて1語。
- 〔例〕名にし負はば → 名に負はば（副助詞）／折しも
- 〔例〕うれ｜し → 「うれ」は言葉にならない（形容詞）／恋しくて → 「恋しく」で1語
- 〔問〕「名にし負はば」の「し」の正体は？（副助詞（強意）／過去「き」の連体形／サ変「す」の連用形）
- 躓き：「恋しくて」を「して」と見てサ変と取る（根拠：問 shi-w11 の誤答の選択肢）。実データ少。
