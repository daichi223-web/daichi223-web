## K. 形容詞・形容動詞

### K-0 形容詞とは【前提】
- 様子・性質・気持ちを表す言葉。活用する。
- 言い切りの形（終止形）は「し」で終わる。「いみじ」のように「じ」で終わる語もある。
- 〔例〕高し・よし・なし・うれし・をかし・いみじ
- 〔例〕形容詞でないもの：書く（動詞。ウ段で終わる）・静かなり（形容動詞）・あり（ラ変動詞）
- 〔問〕形容詞はどれ？（高し／書く／静かなり／あり）
- 躓き：実データ少。「いみじ」の「じ」を打消推量の助動詞「じ」と思う（教科書的な紛れ）。

### K-1 形容動詞とは【前提】
- 様子・性質を表す言葉。言い切りの形は「なり」「たり」で終わる。
- 〔例〕静かなり・あはれなり・あてなり・堂々たり
- 〔例〕形容詞との違い：高し（「し」で終わる）／静かなり（「なり」で終わる）
- 〔問〕形容動詞はどれ？（あはれなり／をかし／書く／花）
- 躓き：実データ少（形容動詞を問うドリルは無い）。名詞＋断定「なり」（花なり）と区別しにくい。見分けは識別の単元で扱う。

### K-2 ク活用とシク活用の見分け方：「なる」を付ける【新】
- 形容詞の活用は、ク活用とシク活用の2つ。終止形はどちらも「〜し」なので、終止形では見分けられない。
- 「なる」を付けて連用形にする。「〜くなる」ならク活用、「〜しくなる」ならシク活用。
- 〔例〕高し→高くなる→ク活用。よし→よくなる→ク活用。わろし→わろくなる→ク活用。
- 〔例〕うれし→うれしくなる→シク活用。をかし→をかしくなる→シク活用。
- 〔例〕いみじ→いみじくなる→シク活用（「じ」で終わる語もシク活用として扱う）。
- 〔問〕「めでたし」はどちら？（ク活用／シク活用／ナリ活用）
- 躓き：「気持ちを表す語ならシク活用」と決めてしまう。「めでたし」「わろし」はク活用（旧解説の一覧にも誤りがあり、2026-11-15 に直した）。ドリルの選択肢には毎回「ナリ活用」「タリ活用」が入る。実データ少（keiyoshi-katsuyo 4件）。

### K-3 ク活用の本活用【新】
- 語尾は（く）・く・し・き・けれ・○。後ろに付く語で活用形を決める（A-4 と同じ）。
- 命令形は無い（○）。未然形の「く」は（ ）付きで、ふつうはカリ活用の「から」を使う（K-6）。
- 〔例〕よし：よく-て／よし。／よき-人／よけれ-ば
- 〔例〕年ごろはわろく書きけるものかな。（絵仏師良秀。「わろく」は動詞「書き」に続く連用形）
- 〔問〕「小倉山あらしの風の寒ければ」の「寒けれ」は何形？（已然形／連体形／未然形／命令形）
- 躓き：連体形「〜き」と已然形「〜けれ」の取りちがえ（ドリル k205 の誤答選択肢）。文末の「〜き」を終止形と答える（K-8）。実データ少（keiyoshi-ku 4件・誤答2件、どの問かは集計の対象外）。

### K-4 シク活用の本活用【新】
- 語尾は（しく）・しく・し・しき・しけれ・○。ク活用の語尾の前に「し」が入った形。
- 終止形だけは「しし」にならず「し」になる（うれし）。
- 〔例〕うれし：うれしく-て／うれし。／うれしき-こと／うれしけれ-ば
- 〔例〕あさましきことかな（絵仏師良秀。体言「こと」の前の連体形）
- 〔問〕「うれし」の終止形はどれ？（うれし／うれしし／うれしき）
- 躓き：実データ少（keiyoshi-shiku 4件・誤答0）。終止形を「うれしし」と作る（内容の分析）。

### K-5 カリ活用（補助活用）の形【新】
- 本活用の連用形「く」に「あり」が付いて縮まった形（よく＋あり→よかり）。だから語尾はラ変「あり」に似る。
- ク活用：から・かり・○・かる・○・かれ。シク活用：しから・しかり・○・しかる・○・しかれ。
- 〔例〕よから-ず・よかり-けり・よかる-べし・よかれ
- 〔例〕うれしから-ず・うれしかり-けり
- 〔問〕「よし」のカリ活用の連用形は？（よかり／よく／よから／よかる）
- 躓き：実データ少。本活用とカリ活用の2列を1つの表と思い、「よく」と「よかり」を混ぜる。カリ活用にもふつう終止形・已然形があると思う（○）。

### K-6 本活用とカリ活用の使い分け【新】
- 後ろに助動詞が来るときは、ふつうカリ活用を使う。「ず」の前も「から」（よからず）。
- 体言・「て」・「ば」「ども」の前と、言い切りは本活用を使う。
- 命令形はカリ活用の「かれ」しかない。
- 〔例〕なき-人／なく-て／なし。（本活用）⇔ なから-ず／なかり-けり（カリ活用）
- 〔例〕わろかりなむ（ちごのそらね。後ろに助動詞が続くのでカリ活用）
- 〔問〕「よ〜けり」の〜に入る形は？（よかり／よく／よき／よし）
- 躓き：実データ少。助動詞「けり」の前で本活用の「よく」を選ぶ（内容の分析）。

### K-7 「多し」は「多かり」を終止形に使う【新】
- カリ活用には、ふつう終止形が無い。ところが「多し」は、「多かり」を終止形として使うことがある。
- 連用形も「多かり」なので、後ろの語で見分ける。
- 〔例〕まだいと足らぬこと多かり。（ドリル k316 の context の一部。「。」で言い切る＝終止形）
- 〔例〕多かり-けり（「けり」の前＝連用形）
- 〔問〕「足らぬこと多かり。」の「多かり」は何形？（終止形／連用形／連体形）
- 躓き：活用表の「−」（カリ活用に終止形が無い）と食い違って見え、連用形と答える（教科書的な紛れ。実データ少）。

### K-8 文末の「〜き」「〜しき」は係り結びの連体形【新】
- 前提：係り結び（助詞の分解で扱う。ぞ・なむ・や・か→連体形）。
- 文の終わりでも、前に「ぞ・なむ・や・か」があると、終止形「〜し」でなく連体形「〜き」「〜しき」で結ぶ。
- 〔例〕見る人ぞなき（ドリル k101 の context。「ぞ」が無ければ「見る人なし」）
- 〔例〕ありしよりもけにものぞ悲しき（ドリル k210 の context の一部）
- 〔問〕「のがるべき方ぞなき」の「なき」は何形？（連体形／終止形／已然形）
- 躓き：文末だから終止形と決めてしまう（ドリル k101・k108・k210 の問いの作り。実データ少）。

### K-9 形容動詞の活用：ナリ活用・タリ活用（ラ変型）【新】
- 語幹＋「なり」「たり」。「に＋あり」「と＋あり」が縮まった形なので、語尾はラ変「あり」と同じ型（ら・り・り・る・れ・れ）。
- ナリ活用：なら・なり（に）・なり・なる・なれ・なれ。タリ活用：たら・たり（と）・たり・たる・たれ・たれ。
- タリ活用は「堂々」のような漢語に付き、和文には少ない。
- 〔例〕静かなら-ず／静かなり-けり／静かなり。／静かなる-とき／静かなれ-ば
- 〔例〕堂々たり。／堂々たる-さま
- 〔問〕「静かなる夜」の「静かなる」は何形？（連体形／終止形／已然形／連用形）
- 躓き：実データ無し（形容動詞のドリルは無い）。終止形「なり」と連体形「なる」の取りちがえ（内容の分析）。

### K-10 形容動詞の連用形「に」「と」【新】
- ナリ活用の連用形は「なり」と「に」の2つ。助動詞の前は主に「なり」、用言の前は「に」になる。
- タリ活用の連用形は「たり」と「と」。
- 〔例〕静かなり-けり ⇔ 静かに-歩む
- 〔例〕いみじうあはれにをかしけれ（野分のまたの日こそ。「あはれに」は形容詞「をかし」に続く連用形）
- 〔例〕堂々と-立つ
- 〔問〕「静かに歩む」の「静かに」は何形？（連用形／連体形／終止形）
- 躓き：実データ無し。「に」を格助詞や断定「なり」の連用形と取る（識別の単元で扱う）。

### K-11 形容詞の語幹【前提】（A-3 を形容詞に当てる）
- 語幹＝活用しても変わらない部分。ク活用は「し」の前まで（高し→高）。シク活用は「しく・し・しき」が語尾なので、語幹は「し」の前まで（うれし→うれ）。
- 〔例〕高し→高、よし→よ、幼し→幼
- 〔例〕うれし→うれ、苦し→苦
- 〔問〕「高し」の語幹は？（高／高し／高く）
- 躓き：語幹の用法（K-13）ではシク活用は「し」まで使うので、語幹そのものと混ぜやすい。

### K-12 「あな」＋語幹で感動を表す【新】
- 感動詞「あな」に語幹が続いて、「ああ、〜だ」と感動を表す。
- 〔例〕あな、わびしと思ひて、（ちごのそらね）
- 〔例〕あなめでたや（ドリル w12 の context の一部）・あなかしこ（手紙の結びの決まった言い方）
- 〔問〕「あな、うれし」の意味は？（ああ、うれしい／うれしくない／うれしいか／うれしくなれ）
- 躓き：実データ少（keiyoshi-gokan 4件・誤答0）。ドリルの誤答選択肢は、疑問（〜か）や命令（〜なれ）と取るもの。

### K-13 ク活用は語幹だけ、シク活用は「し」まで【新】
- 語幹の用法では、ク活用は語幹だけを使う。シク活用は「し」まで（終止形と同じ形）を使う。
- 〔例〕ク活用：高し→あな高、幼し→あな幼や（若紫の君「いで、あな幼や。」）
- 〔例〕シク活用：苦し→あな苦し（母子の別離「あな苦し」）、わびし→あな、わびし
- 〔問〕「高し」（ク活用）で「ああ、高い」と感動を表す形は？（あな高／あな高し／あな高き／あな高く）
- 躓き：ク活用にも「し」を付けて「あな高し」とする（ドリル gokan-02・w01・w02 の誤答選択肢）。

### K-14 語幹＋の＋体言（＋や）で感動を表す【新】
- 語幹（シク活用は「し」まで）に「の」と体言が続き、「なんと〜な…だなあ」と感動を表す。終わりに「や」が付くことが多い。
- 〔例〕あな、かひなのわざや（燕の子安貝。「かひなし」の語幹「かひな」＋の＋わざ＋や。教材の訳「ああ、かいのない（貝のない）ことよ」）
- 〔例〕あなものぐるほしのもの怖ぢや（廃院の怪。シク活用「ものぐるほし」＋の＋もの怖ぢ＋や。教材の訳「まあ何と狂気じみた怖がりようだなあ」）
- 〔例〕をかしの御髪や（なんと美しい御髪だなあ。単元の解説・ドリル w08）
- 〔問〕「をかしの御髪や」が表すのは？（詠嘆／疑問／原因）
- 躓き：終わりの「や」を疑問と取る（ドリル w08 の誤答選択肢「疑問（御髪は美しいか）」）。

### K-15 名詞＋を＋語幹＋み＝「〜が…ので」【新】
- 和歌によく出る。原因・理由を表す。「を」は「〜を」でなく「〜が」と訳す。
- 「を」が省かれることもある（山高み）。
- 「み」はク活用なら語幹に直接付く（寒→寒み）。活用した形（寒し・寒く）には付けない。
- 〔例〕瀬を早み（瀬の流れが速いので。ドリル gokan-03 の context）
- 〔例〕風をいたみ（風が激しいので。ドリル w10）・山高み（山が高いので）
- 〔問〕「瀬を早み」の意味は？（瀬の流れが速いので／瀬を速く下って／瀬は速いけれど）
- 躓き：「を」を現代語の「〜を」と訳す（gokan-03・w05 の誤答選択肢「瀬を速く下って」）。活用した形に「み」を付ける（gokan-06・w03 の誤答選択肢「寒しみ」「寒くみ」）。実データ少。

### K-16 語幹＋げ・さ・み（別の語を作る）【新】
- げ＝〜そうな様子（うれしげなり）。さ＝程度を表す名詞（高さ・深さ）。み＝場所・状態を表す名詞（深み・茂み）。
- 〔例〕うれしげなり（うれしそうな様子だ）
- 〔例〕高さ・深さ／深み・茂み
- 〔問〕程度を表す名詞はどれ？（高さ／高げ／高し／高く）
- 躓き：名詞を作る「み」（深み）と、理由の「み」（山を高み＝K-15）を混同する（ドリル w11 の作り）。実データ少。

## O. 音便

### O-0 音便とは【新】（前提：A-4 の連用形）
- 言いやすいように、語の一部の音が別の音に変わること。
- 主に、連用形に「て」「たり」が続くときに起こる。形容詞の連用形「く」でも起こる。
- 〔例〕書きて→書いて、立ちて→立つて
- 〔例〕うつくしくて→うつくしうて
- 〔問〕音便が起きている形はどれ？（書いて／書きて／書かず／書く）
- 躓き：実データ少（onbin 4件・誤答1件、どの問かは集計の対象外）。音便の形を別の語と思う（内容の分析）。

### O-1 4つの音便の名前は「変わったあとの音」で決まる【新】
- い→イ音便、う→ウ音便、ん→撥音便、っ（つまる音）→促音便。
- 古文では、つまる音「っ」も大きく「つ」と書くことが多い。
- 〔例〕書きて→書いて（イ音便）、思ひて→思うて（ウ音便）
- 〔例〕飛びて→飛んで（撥音便）、立ちて→立つて（促音便）
- 〔問〕「飛びて→飛んで」の音便は？（撥音便／促音便／ウ音便／イ音便）
- 躓き：促音便の「つ」を終止形「立つ」と読む（ドリル w04 の誤答選択肢「立てて」など）。

### O-2 元の形に戻す：終止形から連用形を出す【新】
- 変わる前の音は1つとは限らない。ウ音便の「う」は く・ひ・び・み、撥音便の「ん」は に・び・み・る から来る。
- だから、その語の終止形を思い出し、連用形を作って戻す。撥音便のあとの「で」は「て」に戻す。
- 〔例〕問うて→終止形「問ふ」→連用形「問ひ」→問ひて
- 〔例〕飛んで→「飛ぶ」→飛びて／死んで→「死ぬ」→死にて
- 〔問〕「問うて」の元の形は？（問ひて／問きて／問みて／問りて）
- 躓き：「う」を「く」に戻して「問きて」とする（ドリル onbin-07 の誤答選択肢）。

### O-3 形容詞のウ音便：「〜く」「〜しく」→「〜う」「〜しう」【新】
- 形容詞の連用形「く」が「う」に変わる。戻せば連用形。
- 「〜しう」なら「〜しく」に戻ってシク活用、「〜う」なら「〜く」に戻ってク活用と分かる。
- 〔例〕いみじく→いみじう、うつくしく→うつくしう、恐ろしく→恐ろしう（シク活用）
- 〔例〕おもしろく→おもしろう、こよなく→こよなう（ク活用）
- 〔問〕「いみじう」は何形？（連用形／終止形／連体形）
- 躓き：「〜う」を言い切りの形と思う。種類（ク・シク）を戻さずに決める（ドリル k202・k206・k303・k313・k209・k305 で頻出。実データ少）。

### O-4 撥音便の無表記：書かれない「ん」【新】
- 撥音便の「ん」は書かれないことが多い。
- ラ変型の連体形「〜る」が、助動詞「なり」「めり」の前で「ん」になり、その「ん」が書かれない。
- 〔例〕あるなり→あんなり→あなり／あるめり→あんめり→あめり
- 〔例〕ざるなり→ざんなり→ざなり／多かるなり→多かんなり→多かなり
- 〔問〕「あなり」の元の形は？（あるなり／ありなり／あらなり）
- 躓き：「ありなり」と復元する（ドリル w05 の誤答選択肢）。読解の急所。

### O-5 無表記のあとの「なり」「めり」の意味【新】（前提：助動詞 なり・めり の単元）
- 「あなり」「ざなり」の「なり」は伝聞推定（〜そうだ・〜ようだ）。「あめり」の「めり」は推定（〜ようだ）。
- 断定の「なり」（〜である）ではない。
- 〔例〕都の人は、この鳥を見知らざなり（見知らないそうだ。ドリル w08）
- 〔例〕向かひの岸に人の家あめり（家があるようだ。ドリル w07 の context の一部）
- 〔問〕「貴き聖あなり」の「なり」は？（伝聞推定の助動詞／断定の助動詞／ラ変動詞の一部／形容動詞の語尾）
- 躓き：「なり」を断定と読む（ドリル w06 の誤答選択肢）。
- 接続と意味を分けた：O-4 は形（どこで「ん」が消えるか）、O-5 は意味。
