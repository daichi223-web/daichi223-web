## jodoshi-toha　助動詞とは

### 分析
- **躓きポイント**
  - 実データ少（50件、誤り1件）。問「助動詞の性質として正しいものはどれ？」で「付属語で活用しない」を選ぶ誤り 1/14人。ほぼ全員が解けている。
  - 「付属語」「活用」の区別があいまいだと、助動詞と助詞の違いが言えない（内容から）。助詞にも意味があるので「意味があるか」で分けようとする（toha-02 の誤答選択肢）。
  - 「接続」を「下に続く語」と思いこみやすい。接続は**上の語の活用形**を見ること（教科書的な紛れ）。後の単元の「完了ぬ／打消ず」の識別はこれが土台になる。
  - 助動詞自身も活用し、その形の変わり方が動詞などの型と同じだと知らないと、「けり」に無い連用形を答える（けり x07 で「連用形」7件）。
- **解説ポイント**（要素 C-0 → C-1 → C-2 → C-3 → C1-toha-1）
  - 助動詞＝活用する付属語。活用しない付属語は助詞。
  - 接続＝上の語の形。意味＝訳に出る部分で、1つの助動詞に2つ以上あることが多い。活用＝助動詞自身の形で、下二段型・ラ変型などの型で覚える。
  - 「接続 → 活用 → 意味」の順で見る。
- **前提**
  - 動詞とは・活用とは・活用形6つ（A-1・A-2・A-4）。

## jodoshi-jisei　助動詞 時制系

### 分析
- **躓きポイント**
  - 「せば…まし」の「せ」を過去「き」と見抜けない（根拠：jodoshi-jisei-07 で「サ変動詞」4件・「使役「す」」3件、初回誤答 7/10人。時制系でいちばん多い誤り）。
  - 「き」の接続・活用（根拠：jodoshi-jisei-01「き」の接続で「終止形」2件・「未然形」2件、初回誤答 4/12人／06・w02 已然形で「し」各2件／04「来し方」で「カ変連用形＋副助詞し」2件）。
  - 「き」と「けり」の違い（根拠：jisei-03 で「けり」2件・「両方」1件、3/9人／05 で「人から聞いた話だから」2件）。
  - 「つ」「ぬ」の違いを完了と過去の違いと取る（根拠：w09 で「「つ」は完了、「ぬ」は過去」2件）。
  - 下に推量があるのに完了と答える（根拠：w10「散り【な】む」で「完了」5件、初回誤答 4/6人）。会話・和歌の「けり」を過去と答える（w08 で5件、h03・h04 で各3件）。「すでに」があるのに存続と答える（h07 で4件）。→ これらは各単元の要素（C1-tsunu-1・C1-keri-4・C1-tariri-2）で扱う。時制系では「どの組にも2つめの意味がある」ことだけを教える。
- **解説ポイント**（要素 C1-jisei-1 → C1-jisei-2 → C1-ki-1 → C1-ki-2 → C1-ki-3）
  - 6つを意味で3組に：き・けり＝過去、つ・ぬ＝完了、たり・り＝完了。2つめの意味は 詠嘆・強意・存続。
  - 接続は5つが連用形、「り」だけサ変の未然形・四段の已然形。「き」はカ変・サ変には未然形にも付く。
  - 「き」は自分の体験。活用 せ・○・き・し・しか・○（特殊型）。未然形「せ」は「せば…まし」の中だけ。「き」はこの単元にしか単独の解説が無いので、ここで3つの要素に分けて扱う。
- **前提**
  - 助動詞とは（C-0〜C-3）。活用形の名前（A-4）。係り結び（ぞ・なむ→連体形、こそ→已然形）は「き」の結びの形で少し使う。
- 既存の解説「つ・ぬ（完了・強意）」の強意の書き方は、2026-11-16 の先生の決定（#1）で直してある。

## jodoshi-keri　助動詞「けり」

### 分析
- **躓きポイント**
  - 引用の「と」の上の「けり」を連用形と答える（根拠：問 jodoshi-keri-x07「見て【けり】とだに」で「連用形」7件、初回誤答 4/5人／x12「隠れ忍びてあるなり【けり】、と」で「連用形」4件・2/4人）。「けり」には連用形が無い（○）ことと、引用の「と」の上は言い切りの形になることが結びついていない。
  - 気づきの「けれ」を過去と答える（根拠：m05「今見れば、かうこそ燃え【けれ】と、心得つるなり」で「過去」3件、初回誤答 3/4人）。地の文の中の心内語の気づきを見分けられない。
  - 係り結びの形の取り違え（根拠：keri-02「ぞ・なむ」の結びで「けれ」2件・「けり」2件／keri-03「こそ」の結びで「けり」「ける」各1件）。
  - 時制系でも同じ傾向（会話の「けり」を過去と答える 5件、「来にけるかな」を過去 3件）。
- **解説ポイント**（要素 C1-keri-1 → C1-keri-2 → C1-keri-3 → C1-keri-4 → C1-keri-5）
  - 連用形に付く。けら・○・けり・ける・けれ・○（ラ変型）。何形かは下の語で決める（体言・かな→ける、ば・ど→けれ、。・引用の と→けり）。
  - 地の文→過去「〜た」。和歌・会話・心内語の気づき→詠嘆「〜だなあ」。過去と詠嘆は、見る所が別なので別の要素にした。
  - 「ぞ・なむ・や・か」→「ける」、「こそ」→「けれ」。結びの形と意味は別に決める。
- **前提**
  - 時制系の単元（「き」との違い）。係り結び。地の文・会話文・和歌の区別（「 」と五七五七七）。
- 既存の問題の扱い（2026-11-16 までに決まったもの）：keri-m06 は「過去」に直してある。keri-d08 の解説は発見の詠嘆に、x10 の訳は問うている文に直してある。keri-d03（心内語の中の「ける」）は、教材の本文データが過去なので今のまま（先生の決定 #2）。

## jodoshi-tsu　助動詞「つ」（完了）

### 分析
- **躓きポイント**
  - 「て＋けり」を強意と答える（根拠：問 jodoshi-tsu-c01「この男、かいま見【て】けり」で「強意」4件、初回誤答 3/4人）。「下に何か続けば強意」と覚えていて、「けり」「き」が推量でないことを確かめていない。
  - 未然形「て」と連用形「て」の取り違え（根拠：x03「乳母かへ【て】む」で「連用形」「連体形」各1件）。未然形・連用形が同じ形なので、下の語で決めることが分かっていない。
  - 接続（根拠：tsu-01 で「未然形」「終止形」各1件）。
  - 時制系でも「つ」「ぬ」を「完了と過去」の違いと取る誤り 2件（jodoshi-jisei-w09）。
  - 完了の「て」と接続助詞「て」の混同（教科書的な紛れ）。
  - 「下に推量があれば必ず強意」と覚えて、原因推量の「らむ」の前の「つ」も強意と答える（作問ルール `kobun-jodoshi-quiz-correctness` §1 の紛れ。実データ少）。
- **解説ポイント**（要素 C1-tsu-1 → C1-tsu-2 → C1-tsu-3 → C1-tsunu-1 → C1-tsunu-2）
  - 連用形に付き、て・て・つ・つる・つれ・てよ（下二段型）。未然形と連用形は下の語で見分ける。

## jodoshi-nu　助動詞「ぬ」（完了）

### 分析
- **躓きポイント**
  - 実データ少（単元 93件・6人。問いごとの記録は2問だけ）。
  - 「にけり」「にき」の「に」を終止形と答える（根拠：問 jodoshi-nu-01「暮れにけり」「散りにき」の「に」で「終止形」2件）。
  - 「な＋む」を完了と答える（根拠：時制系 jodoshi-jisei-w10「散り【な】む」で「完了」5件・初回誤答 4/6人）。「な」が「ぬ」の未然形だと気づかない。
  - 打消「ず」の連体形「ぬ」との取り違え（教科書的な紛れ。既存の解説も「最重要」とする）。とくに下二段の「見え」「暮れ」「逃げ」のように未然形と連用形が同じ形の語で迷う。
- **解説ポイント**（要素 C1-nu-1 → C1-nu-2 → C1-nu-3 → C1-tsunu-1 → C1-nuzu-1）
  - 連用形に付き、な・に・ぬ・ぬる・ぬれ・ね（ナ変型）。「にけり・にき」の「に」は連用形。
  - 完了が基本で、自然な成り行きに多い。強意は2つの形：下に推量（なむ・ぬべし・なまし）、命令形「ね」。急かす文末「日も暮れぬ」も強意（`kobun-nu-tsu-kanyu-kakujutsu`、nu-c01）。
  - 完了「ぬ」と打消「ぬ」：上が連用形→完了、未然形→打消。決まらないときは下の語（体言なら打消の連体形。完了の連体形は「ぬる」）。
  - 「らむ」「けむ」の前の例外（C1-tsunu-2）は「つ」の単元で教え、この単元では強意の part の中で1文だけふれる（parts は5つまで）。
- **前提**
  - 時制系の単元。「つ」の単元（強意の考え方・らむ けむ の例外）。ナ変の活用（A-6）。打消「ず」の活用（ず・ず・ず・ぬ・ね）は「ず」の単元でも学ぶ。
- 既存の問題の扱い：nu-h04 は「ぬ」の正体の問いに直してある（先生の決定 #4）。nu-d07 の解説は命令形の強意に、textExamples は「寝入りたまひにけり」に直してある。
- 〔要確認〕既存の解説「意味」の強意の欄は「「ぬ＋べし」「な＋む」の組み合わせ」だけで、命令形「ね」（nu-d07 は強意）と「なまし」（nu-d08）が無い。「つ」と時制系の節は先生の決定 #1・#3 で直したが、この節は直していない。同じ書き方（「下に推量が続く形（なむ・ぬべし・なまし など）、命令形「ね」」）にそろえるか要判断。
- 〔要確認〕問 nu-x08「何の身にこのたびはなり【ぬ】らむ」の解説は「らむは現在推量で…完了のまま」と書く。知識 `kobun-tsu-nu-kakujutsu` では、完了のままになるのは原因推量の「らむ」で、現在推量なら原則強意。問いは正体（完了「ぬ」）を問うので正解は変わらないが、解説の「現在推量」の言い方を直すか要判断。
- 問 nu-05「年も暮れぬ。」の正解「完了」と c01「日も暮れぬ」の正解「強意」は、前者が正体（完了の助動詞か打消か）を問う識別の問いなので矛盾しない。台本の識別の part では「完了の助動詞「ぬ」」と言う。

### 分析
- **躓きポイント**
  - 実データ少（単元 88件・6人。問いごとの記録は1問だけ：jodoshi-tari-03「咲く」に「たり」で「咲かたり」1件）。

## jodoshi-ri　助動詞「り」（完了・存続）

### 分析
- **躓きポイント**
  - 実データ少（単元 66件・5人。問いごとの記録は1問だけ：jodoshi-ri-01「咲ける花」の「る」で「終止形」1件）。

  - 上がエ段→「り」、ア段→受身などの「る」。

- **前提**
  - 「たり」の単元。四段活用・サ変の活用（とくに已然形・未然形。A-5・A-6）。

## jodoshi-zu　助動詞「ず」（打消）

### 分析
- **躓きポイント**
  - 実データ少（単元 88件・5人。問いごとの記録は1問だけ：jodoshi-zu-01、誤り0）。
  - 連体形「ぬ」・已然形「ね」を、完了「ぬ」の終止形・命令形と取り違える（教科書的な紛れ。既存の解説「重要な識別」、ドリル zu-x01〜x12・h02 が扱う）。とくに「見え」「濡れ」「おぼえ」のように未然形と連用形が同じ形の語。
  - ザリ活用（ざら・ざり・ざる・ざれ）を使う場面が分からない（内容から。ドリル zu-04・08・c13 ほか）。
  - 「来ぬ」を「こぬ」（打消）と「きぬ」（完了）で読み分けられない（ドリル zu-y02 が扱う）。
- **解説ポイント**（要素 C1-zu-1 → C1-zu-2 → C1-zu-3 → C1-zu-4 → C1-nuzu-1）
  - 未然形に付く。本活用 ず・ず・ず・ぬ・ね・○（特殊型）と、ザリ活用 ざら・ざり・○・ざる・ざれ・ざれ（ラ変型）。下に助動詞が続くときは多くはザリ活用。
  - 意味は打消「〜ない」の一つだけなので、形の見分けが中心。
  - 打消の「ぬ」「ね」と完了の「ぬ」「ね」：上が未然形か連用形か。決まらないときは下の語（体言・「ば」・「こそ」の結び）。この見分けは「ぬ」の単元と同じ要素（C1-nuzu-1）を、「ず」の例で教える。
- **前提**
  - 助動詞とは（接続）。「ぬ」の単元（完了の「ぬ」の活用）。係り結び（こそ→已然形）。
- 既存の問題の扱い：解説「接続と活用」のザリ活用の使い分けは「多くは」に直し、本活用の「ぬ」に付く断定「なり」の例を足してある。識別の問いの手がかり《 》（zu-x02・x03・x06・x07・x09）は、決め手の語に引き直してある。
