# 識別（7単元）

識別の単元は、どれも同じ手順で解く。
- ①直前の語（接続・活用形）を見る。
- ②すぐ後ろの語を見る。
- ③取り除く・切り離すテストをする。
- ④決めた正体で訳して確かめる。

台本もこの順で組み、各段階のあとに問いを入れた。

実データ（`reports/drill-stumbles-2026-11-15.json`）があるのは「に」（124件・6人）と「なむ」（65件・4人）だけ。ほかの5単元は集計の基準（3人以上・5件以上）に届いていないので、解説とドリルの中身から分析した。

---

## shikibetsu　紛らわしい語の識別

### 分析
- **躓きポイント**
  - 見た目の形（「ぬ」「に」）や訳の感じだけで正体を決めてしまう。識別は、前の語の活用形から見るのが基本になる（根拠：実データなし（この単元にドリルが無い）。下位単元の「に」で、「夢にやあらむ」を「格助詞」「完了」と答えた誤りが初回3/3人。下の語「あら（あり）」を見ていない）。
  - 前の語が未然形か連用形かを言えない。「咲か／咲き」の1字のちがいが手がかりになることに気づかない（根拠：教科書的な紛れ。「ぬ」「なむ」の識別はこの1字で決まる）。
  - 語の一部（静かに・死ぬ・忘る）を助詞・助動詞として切り出してしまう（根拠：下位単元のドリルの誤答の選択肢「格助詞」「受身「る」」）。
  - 〔要確認〕既存の解説「最重要 3 語の判別」と keyPoints は「に（5 通り）」としている。下位単元 shikibetsu-ni は「副詞の一部」を入れて6つ。数がずれている。
  - 〔要確認〕既存の解説「最重要 3 語の判別」の「に」の表は、形容動詞の連用形の判別法を「「だ」に置換可能」としている。これだと「京に」も「京だ」と言えるので、格助詞と分けられない。shikibetsu-ni の「「に」を含めて一語で状態の意味」にそろえた方がよい。
  - 〔要確認〕既存の解説「活用語尾系の識別」の「せ」の表に「サ変「す」の未然／已然／命令形」とある。サ変の已然形は「すれ」、命令形は「せよ」なので、「せ」1字になるのは未然形だけ。
  - 〔要確認〕既存の解説「助動詞系の識別」の「る／れ」の表に「自発「らる」（活用の一部が「れ」）｜上記以外の未然形」とある。「らる」は受身・尊敬・可能・自発の4つの意味を持ち、自発だけではない。「れ」1字ではなく「られ」の形で現れる。
  - 〔要確認〕既存の解説「助詞系の識別」の「が」に「直後に用言が来て文が続くなら接続助詞」とある。主格の格助詞「が」も下に述語（用言）が来るので、この基準だけでは分けられない。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 識別は「前の語 → 後ろの語 → 取ってみる → 訳して確かめる」の順。
  - 助動詞は前の語の形（接続）が決まっているので、前の語の活用形で候補がしぼれる。
  - 取り除いても文が成り立てば助詞（係助詞「なむ」・副助詞「し」）。切ると前が言葉として残らなければ、語の一部。
  - 訳は最後の確かめに使う。訳の感じから先に決めない。
- **前提**（先に要る用語・単元）
  - 活用形（未然形・連用形・連体形・已然形）と動詞の活用の種類。
  - 助動詞の接続（「ず」は未然形、「けり」は連用形）。
  - 係り結び（ぞ・なむ・や・か→連体形）。

## shikibetsu-ni　「に」の識別

### 分析
- **躓きポイント**
  - 「夢にやあらむ」のように体言の後ろの「に」を、格助詞と決めてしまう。間に「や」「こそ」「は」が入ると、後ろの「あり」を見落とす（根拠：問「夢にやあらむ」で「格助詞」2・「完了「ぬ」の連用形」2、初回誤答3/3人。問「不義をよしとする【に】は《あら》ず」で「接続助詞」1・「完了」1）。
  - 反対に、ただの場所の「に」を断定と答える。「あり」が後ろに無いことを確かめていない（根拠：問「京に着きぬ」で「断定「なり」の連用形」2）。
  - 「に」が完了の助動詞「ぬ」の連用形だとつながっていない。字の似た「なり」や、同じ完了の「り」を選ぶ（根拠：問「「散りにき」の「に」と同じものを含むのは」で「散るなり」2・「散れり」1、初回誤答3/4人）。
  - 連体形＋に（接続助詞）を、断定・格助詞と取りちがえる（根拠：問「待つに、人来ず」で「断定」1・「格助詞」1）。
  - 〔要確認〕ドリル shikibetsu-ni-c16（「散れるやう【に】ぞありける」、正解＝断定）。「やうに」を比況の助動詞「やうなり」の連用形とする教科書もある。名詞「やう」＋断定と分けるかどうかの扱いをそろえたい。
  - 〔要確認〕ドリル shikibetsu-ni-c10（「何《と》【に】はなけれども」、正解＝断定）。解説が「体言・連体形＋なり」になっているが、前は助詞「と」。解説を例文に合わせる必要がある。
  - 〔要確認〕本文から作ったドリルの解説の訳が、例文と別の文になっているものがある。c06（「もとの身にして」に「月は以前と同じではないのか」）と c11（「言ふべきにあらず」に別の文の訳）。
  - 補足：教材の識別レイヤーでは、連体形＋「に」が格助詞か接続助詞かで学説が分かれる箇所を、両方正解・△にしている（`src/lib/kobun/shikibetsuYure.ts`）。台本では、ドリルどおり「連体形の後ろで文が続く＝接続助詞」とだけ教えた。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 「に」は完了「ぬ」の連用形でもある（な・に・ぬ・ぬる・ぬれ・ね）。前が連用形で後ろに「き・けり・たり」なら完了。
  - 後ろに「あり」系（間に や・こそ・は が入ってもよい）が来て「〜であって」と訳せれば断定。体言の後ろでも、すぐ格助詞と決めない。
  - 体言の後ろで「あり」が無ければ格助詞、連体形の後ろで文が続けば接続助詞。
  - 「静かに」「げに」は「に」までで1語。「に」だけを取り出さない。
- **前提**（先に要る用語・単元）
  - 完了「ぬ」の活用（jodoshi-nu）、断定「なり」（jodoshi-dantei）。
  - 連用形・連体形の見分け、体言。
  - 格助詞・接続助詞（joshi-kaku・joshi-setsuzoku）、形容動詞。

## shikibetsu-nu-ne　「ぬ」「ね」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 「ぬ」を見ると、前の語の形を見ないで完了か打消かを決めてしまう。今の言葉の「知らぬ」（打消）の感覚と、「〜ぬ」＝完了の思い込みの両方がある（根拠：ドリルの対比問「帰りぬ／帰らぬ」、誤答の選択肢「完了「ぬ」の終止形」「打消「ず」の連体形」が全問に並ぶ）。
  - 文末の「ぬ」はすべて完了と即断する。「花や咲かぬ」のように、係り結びで連体形になった打消を見落とす（根拠：問 shikibetsu-nu-ne-09「文末なのに打消の「ぬ」。なぜ？」）。
  - 「見え」「見」のように未然形と連用形が同じ形の動詞では、前の形で決まらないことに気づかない（根拠：問「見えぬ山」「月見ねば」）。
  - 「死ぬ」「往ぬ」「往ね」のナ変動詞の語尾を、助動詞と取りちがえる（根拠：誤答の選択肢「完了「ぬ」」「完了「ぬ」の命令形」）。
  - 〔要確認〕ドリルの多く（shikibetsu-nu-ne-01・02・08・10、c01〜c16）が、正体を問う問いの誤答の選択肢に「強意」を入れている。強意（確述）は完了の助動詞「ぬ」の意味の1つなので、正体の選択肢と意味の選択肢がまざっている。決まり（kobun-nu-tsu-kanyu-kakujutsu）では、文末の「ぬ」（「日も暮れぬ」）も強意（確述）になりうる。そのため「風立ちぬ」（01）で「強意」を選んでも、誤りと言い切れない。正体の問いでは「強意」を外す（または「ナ変動詞の語尾」などに替える）案。
  - 〔要確認〕本文から作ったドリルの解説の訳が、例文と別の文になっているものがある（c01・c05・c06・c10・c13）。また c02〜c16 の打消の解説に、決め手（未然形接続）の説明が無い。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 未然形＋ぬ・ね＝打消「ず」（連体形ぬ・已然形ね）、連用形＋ぬ・ね＝完了「ぬ」（終止形ぬ・命令形ね）。四段動詞なら前の1字の母音（ア段／イ段）で決まる。
  - 前の形で決まらないときは、形と位置を見る。体言の前で「ぬ」のままなら打消、「ぬる・ぬれ」なら完了。
  - 文末でも、係助詞があれば連体形の結びになる。文末＝完了と決めない。
  - 「死ぬ・往ぬ」はナ変動詞。完了の「ぬ」は下に「む・べし」が来ると強意（「ぬべし」＝きっと〜だろう）。正体は完了の助動詞「ぬ」のまま。
- **前提**（先に要る用語・単元）
  - 打消「ず」（jodoshi-zu）・完了「ぬ」（jodoshi-nu）の活用表。
  - 未然形・連用形の見分け、下二段活用・上一段活用（未然形と連用形が同じ形）。
  - 係り結び、ナ変動詞（変格活用）。

## shikibetsu-namu　「なむ」の識別

### 分析
- **躓きポイント**
  - 実データ少（65件・4人、誤答10・初回誤答5）。選択肢ごとの内訳が出たのは1問だけ。
  - 連用形＋なむ（強意＋推量）を、願望「〜してほしい」と取る。前の1字（り／ら）の見分けがあいまい（根拠：問「日暮れて鳥は山へ《帰り》【なむ】」で「帰ってほしい」1）。
  - 「死なむ」「往なむ」を、「なむ」で1語と見て、強意＋推量や願望と答える（根拠：ドリルの誤答の選択肢「強意「ぬ」＋推量「む」」「願望の終助詞」。ナ変の「な」は動詞の一部）。
  - 係助詞の「なむ」は、取り除くテストを知っていれば正答できている（根拠：係助詞の2問（w10・w12）は初回誤答0/4人）。
  - 〔要確認〕ドリル shikibetsu-namu-07 と shikibetsu-namu-w06 は、問い・選択肢・正解がほぼ同じ（「雨なむ降りける」の除去テスト）。どちらかを差し替えてよいか。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 前が連用形＝強意「ぬ」＋推量「む」（きっと〜だろう）、未然形＝願望の終助詞（〜してほしい）、体言・助詞＝係助詞（訳さない）、「死な・往な」＝ナ変＋「む」。
  - 四段動詞では前の1字（帰り／帰ら）で意味が逆になる。
  - 取り除いて文が成り立てば係助詞。取るときは結びの連体形も終止形に戻す。
  - 強意＋推量の「なむ」は、完了「ぬ」の未然形「な」＋「む」の2語。
- **前提**（先に要る用語・単元）
  - 未然形・連用形の見分け。完了「ぬ」の活用（未然形「な」）、推量「む」。

## shikibetsu-ru-re　「る」「れ」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 母音のきまり（ア段＋る・れ＝受身系）を当てはめると、「流れ」「枯れ」が受身に見えてしまう。「流」「枯」の音は「が」「か」でア段だからだ（根拠：問「涙流れて」「枯れたる木」の誤答の選択肢「受身「る」の連用形」。解説にも「受身なら「流さる」のはず」とある）。台本では、母音を見る前に「切ってみる（一語テスト）」をする順にした。既存の解説は①母音→②一語テストの順だが、中身は変えていない。
  - エ段＋る・れの「り」を、受身の「る」と混同する。完了・存続の「り」が「サ変の未然形・四段の已然形」に付くことが身についていない（根拠：問「書ける文」「門に立てれば」の誤答の選択肢）。
  - 「る」と決まったあと、4つの意味（尊敬・自発・可能・受身）の選び方があいまいになる（根拠：問「家に帰られず」「思ひ出でられて」）。
  - 〔要確認〕本文から作ったドリルの解説の訳が、例文と別の文になっているものがある（c01・c02・c07・c12・c16）。
  - 〔要確認〕本文から作ったドリル（c03・c05 ほか）の選択肢「可能のみ」は意味の選択肢で、正体の問いに合っていない。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - まず「る・れ」を切って、前が動詞として残るか確かめる（忘る・流れ・枯れは動詞の一部）。
  - ア段（未然形）＋る・れ＝受身・尊敬・可能・自発の「る」。エ段（サ変未然形・四段已然形）＋る・れ＝完了・存続の「り」。
  - 「る」の意味は、尊敬（主語が高貴）→自発（心の動き）→可能（打消を伴う）→受身の順に考える。
- **前提**（先に要る用語・単元）
  - 助動詞「る・らる」（jodoshi-ru）、完了・存続「り」（jodoshi-ri）。
  - 四段活用の未然形・已然形、下二段活用の動詞（流る・枯る・忘る）。

## shikibetsu-nari　「なり」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 断定（体言・連体形接続）と伝聞推定（終止形接続）の区別が、四段動詞のように終止形と連体形が同じ形の語ではつかない。音・声の場面という決め手を使えない（根拠：問「（隣の部屋で）人泣くなり」、本文の問 c10「人も《とふ》【なり】」・c16「と《奏す》【なり】」が伝聞推定）。
  - 撥音便（あんなり・なんなり・ざんなり）を伝聞推定の目印として知らない（根拠：問「奥に人あんなり」）。
  - 「静かなり」「清げなり」の形容動詞を、体言＋断定と混同する（根拠：問「清げなり」の誤答の選択肢「断定「なり」」）。
  - 「春なれば」（断定）と「春になれば」（動詞）の区別（根拠：問 shikibetsu-nari-06）。
  - 〔要確認〕本文から作ったドリルの解説の訳が、例文と別の文になっているものがある。c14（「憂き身なりけり」に『落窪の君』の別の文の訳）と c10（歌の上の句の訳だけ）。c10・c16 は伝聞推定と判断した理由が解説に無い。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 体言・連体形＋なり＝断定「〜である」、終止形＋なり＝伝聞推定「〜らしい・〜が聞こえる」。
  - 撥音便（あんなり・なんなり・ざんなり、「ん」の無表記も）は伝聞推定の目印。
  - 終止形と連体形が同じ形なら、音・声を根拠にした文かどうかで決める。
  - 「なり」までで1語の形容動詞（名詞として使えない部分＋なり）と、「に＋なる」の動詞「成る」。
- **前提**（先に要る用語・単元）
  - 断定「なり」（jodoshi-dantei）、伝聞推定「なり」（jodoshi-nari）。
  - 終止形・連体形のちがい（上二段「落つ／落つる」、サ変「す／する」）、音便。
  - 形容動詞（ナリ活用）。

## shikibetsu-shi　「し」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 過去「き」の連体形「し」と、サ変「す」の連用形「し」の区別。後ろの語（体言か、「て・けり」か）を見ていない（根拠：問「見し夢／物語しけり」、1文に2つの「し」がある問 shikibetsu-shi-w12）。
  - 「せし」「こし（来し）」の特殊な付き方を知らない。「せし」をサ変連用形＋副助詞などと分けてしまう（根拠：問 shikibetsu-shi-08 の誤答の選択肢「サ変連用形「せ」＋副助詞「し」」、問 w05 の誤答の選択肢「しし事」）。
  - 「恋しくて」の「し」を、「して」に見えてサ変と早合点する（根拠：問 shikibetsu-shi-w11 の解説「サ変「して」と早合点しない」）。
  - 「過ぎにし年」の「にし」を、完了「に」＋過去「し」と分けられない（根拠：問 shikibetsu-shi-09・w07）。
  - 〔要確認〕既存の解説「4つの「し」」の表は、形容詞の語尾を「一語の終止形」とだけしている。ドリル w11 は連用形（恋しく）の「し」を「形容詞の連用形語尾」として出しているので、表に連用形の場合も入れたい。なお「恋しく」の活用語尾は「しく」で、「し」はその一部にあたる。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - し＋体言＝過去「き」の連体形（前は連用形）。係り結びの結びで文末に来ることもある。
  - し＋て・けり＝サ変「す」の連用形。
  - 取り除いても意味が通る＝強めの副助詞（名にし負はば・折しも）。「し」までで1語＝形容詞の語尾。
  - 過去「き」はカ変に「こし」、サ変に「せし」と付く。「にし」＝完了「ぬ」の連用形＋過去「き」の連体形。
- **前提**（先に要る用語・単元）
  - 過去「き」の活用（（せ）・○・き・し・しか・○）と接続（jodoshi-jisei）。
  - サ変・カ変の活用（変格活用）、形容詞のシク活用。
  - 連用形・連体形、体言。
