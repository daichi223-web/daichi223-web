## shikibetsu　紛らわしい語の識別

### 分析
- **躓きポイント**
  - 見た目の形（「ぬ」「に」）や訳の感じだけで正体を決めてしまう。識別は、前の語の活用形から見るのが基本になる（根拠：実データなし（この単元にドリルが無い）。下位単元の「に」で、「夢にやあらむ」を「格助詞」「完了」と答えた誤りが初回3/3人。下の語「あら（あり）」を見ていない）。
  - 前の語が未然形か連用形かを言えない。「咲か／咲き」の1字のちがいが手がかりになることに気づかない（根拠：教科書的な紛れ。「ぬ」「なむ」の識別はこの1字で決まる）。
  - 語の一部（静かに・死ぬ・流れ）を助詞・助動詞として切り出してしまう（根拠：下位単元のドリルの誤答の選択肢「格助詞」「受身「る」の連用形」）。
  - 修正済み（2026-11-16）：節「最重要 3 語の判別」の「に」を6通りに（副詞の一部を追加）、形容動詞の判別法を「「に」を含めて一語で状態の意味」に。節「活用語尾系の識別」の「せ」を「サ変「す」の未然形」だけに。節「助動詞系の識別」の「らる」を4つの意味に。節「助詞系の識別」の「が」の判別を「連体形の下に体言を補えるか」に。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 識別とは、同じ形の語の正体を見分けること。正体で訳が変わる（S-0）。
  - 手順1：助動詞は前の語の形（接続）が決まっているので、直前の活用形で候補がしぼれる（S-1）。
  - 手順2：後ろの語も、前の形を決める。間に係助詞が入っても先まで見る（S-2）。
  - 手順3：取り除いて文が成り立てば強めるだけの助詞、前が言葉として残らなければ語の一部（S-3）。
  - 手順4：訳を当てはめて確かめる。訳の感じから先に決めない（S-4）。
- **前提**（先に要る用語・単元）
  - A-4（活用形6つ）、C-1（接続）。
  - 未然形・連用形・連体形・終止形の見分け、体言。

## shikibetsu-ni　「に」の識別

### 分析
- **躓きポイント**
  - 「夢にやあらむ」のように体言の後ろの「に」を、格助詞と決めてしまう。間に「や」「こそ」「は」が入ると、後ろの「あり」を見落とす（根拠：問「夢にやあらむ」で「格助詞」2・「完了「ぬ」の連用形」2、初回誤答3/3人。問「不義をよしとする【に】は《あら》ず」で「接続助詞」1・「完了」1）。→ S-12
  - 反対に、ただの場所の「に」を断定と答える。「あり」が後ろに無いことを確かめていない（根拠：問「京に着きぬ」で「断定「なり」の連用形」2）。→ S-14
  - 「に」が完了の助動詞「ぬ」の連用形だとつながっていない。字の似た「なり」や、同じ完了の「り」を選ぶ（根拠：問「「散りにき」の「に」と同じものを含むのは」で「散るなり」2・「散れり」1、初回誤答3/4人）。→ S-10
  - 連体形＋に（接続助詞）を、断定・格助詞と取りちがえる（根拠：問「待つに、人来ず」で「断定」1・「格助詞」1）。→ S-14
  - 修正済み（2026-11-16）：c16（「散れるやう【に】ぞありける」）は名詞「やう」＋断定で残し、解説を決め手に合わせた（先生の決定 22）。c10（「何《と》【に】は」）の解説を「代名詞＋格助詞の後ろ、下に「はなけれ」」に直した。c06・c11 の解説の訳を例文の訳に直した。
  - 補足：教材の識別レイヤーでは、連体形＋「に」が格助詞か接続助詞かで学説が分かれる箇所を、両方正解・△にしている（`src/lib/kobun/shikibetsuYure.ts`）。台本では、ドリルどおり「連体形の後ろで文が続く＝接続助詞」とだけ教えた。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 「に」は完了「ぬ」の連用形でもあり、断定「なり」の連用形でもある（S-10）。
  - 手順1：前が連用形なら完了を考える。体言・連体形の後ろは断定がまだ残る（S-11）。
  - 手順2：後ろに「き・けり・たり」なら完了、「あり」系（間に や・こそ・は・も）なら断定（S-12）。
  - 手順3：「静かに」「げに」は「に」までで1語（S-13）。
  - 手順4：「〜であって」で通れば断定。通らなければ、体言の後ろは格助詞、連体形の後ろで文が続けば接続助詞（S-14）。
- **前提**（先に要る用語・単元）
  - 完了「ぬ」の活用（jodoshi-nu）、断定「なり」（jodoshi-dantei）。
  - 連用形・連体形の見分け、体言。
  - 格助詞・接続助詞（joshi-kaku・joshi-setsuzoku）、形容動詞（keiyoshi-katsuyo）。

## shikibetsu-nu-ne　「ぬ」「ね」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 「ぬ」を見ると、前の語の形を見ないで完了か打消かを決めてしまう。今の言葉の「知らぬ」（打消）の感覚と、「〜ぬ」＝完了の思い込みの両方がある（根拠：ドリルの対比問「帰りぬ／帰らぬ」、誤答の選択肢「完了「ぬ」の終止形」「打消「ず」の連体形」が全問に並ぶ）。→ S-21
  - 文末の「ぬ」はすべて完了と即断する。「花や咲かぬ」のように、係り結びで連体形になった打消を見落とす（根拠：問 shikibetsu-nu-ne-09「文末なのに打消の「ぬ」。なぜ？」）。→ S-22
  - 「見え」「見」のように未然形と連用形が同じ形の動詞では、前の形で決まらないことに気づかない（根拠：問「見えぬ山」「月見ねば」）。→ S-22
  - 「死ぬ」「往ぬ」「往ね」のナ変動詞の語尾を、助動詞と取りちがえる（根拠：誤答の選択肢「完了「ぬ」」「完了「ぬ」の命令形」）。→ S-23
  - 修正済み（2026-11-16）：正体の問いの選択肢にあった「強意」（意味の選択肢）を外した（01・02・03・08・10、c01〜c16）。本文から作ったドリルの解説の訳と決め手を、例文に合わせて直した。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 打消「ず」は連体形「ぬ」・已然形「ね」、完了「ぬ」は終止形「ぬ」・命令形「ね」。「ぬる・ぬれ」は完了だけ（S-20）。
  - 手順1：未然形＋ぬ・ね＝打消、連用形＋ぬ・ね＝完了。四段動詞なら前の1字のア段／イ段で決まる（S-21）。
  - 手順2：前の形で決まらないときは、後ろと位置。体言の前の「ぬ」は打消、ね＋ば・どもは打消、文末で言い切る「ぬ」は完了。ただし係助詞の結びは連体形（S-22）。
  - 手順3：「死ぬ・往ぬ」はナ変動詞（S-23）。
  - 手順4：打消「〜ない」・完了「〜た」を当てて確かめる。完了「ぬ」は下に む・べし が来たり命令形だったりすると強意（S-24。2026-11-16 の決定）。
- **前提**（先に要る用語・単元）
  - 打消「ず」（jodoshi-zu）・完了「ぬ」（jodoshi-nu）の活用表。
  - 未然形・連用形の見分け（A-0 段、A-4）、下二段活用・上一段活用（未然形と連用形が同じ形、A-7）。
  - 係り結び、ナ変動詞（A-6）。

## shikibetsu-namu　「なむ」の識別

### 分析
- **躓きポイント**

## shikibetsu-ru-re　「る」「れ」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 段のきまり（ア段＋る・れ＝助動詞「る」）を当てはめると、「流れ」「枯れ」が受身に見えてしまう。「流」「枯」の音は「が」「か」でア段だからだ（根拠：問「涙流れて」「枯れたる木」の誤答の選択肢「受身「る」の連用形」。解説にも「受身なら「流さる」のはず」とある）。台本では、段を見る前に「切ってみる（手順3）」をする順にした（S-41）。既存の解説は①段→②一語テストの順だが、中身は変えていない。
  - エ段＋る・れの「り」を、受身の「る」と混同する。完了・存続の「り」が「サ変の未然形・四段の已然形」に付くことが身についていない（根拠：問「書ける文」「門に立てれば」の誤答の選択肢）。→ S-42
  - 「る」と決まったあと、4つの意味（尊敬・自発・可能・受身）の選び方があいまいになる（根拠：問「家に帰られず」「思ひ出でられて」）。→ 前提の part（jodoshi-ru）
  - 修正済み（2026-11-16）：本文から作ったドリルの解説の訳を例文の訳に直した（c01・c02・c07・c12・c16）。正体の問いの選択肢「可能のみ」を「完了・存続「り」の終止形」に替えた（c03 ほか9問、先生の決定 24）。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 3つの正体：助動詞「る」（れ・れ・る・るる・るれ・れよ）、完了・存続「り」（連体形「る」・已然形と命令形「れ」）、動詞の一部（S-40）。
  - 手順3を先に：「る・れ」を切って、前が動詞として残るか（忘る・流れ・枯れは動詞の一部）（S-41）。
  - 手順1：ア段（未然形）＋る・れ＝助動詞「る」。エ段（サ変未然形・四段已然形）＋る・れ＝完了・存続「り」（S-42）。
  - 手順4：「り」は「〜ている・〜てある・〜た」、「る」は「〜れる・〜られる」（S-43）。
  - 「る」の意味は、尊敬（主語が高貴）・自発（心の動き）・可能（打消を伴う）・受身から選ぶ（jodoshi-ru の要素）。
- **前提**（先に要る用語・単元）
  - 助動詞「る・らる」（jodoshi-ru）、完了・存続「り」（jodoshi-ri）。
  - 段（A-0）、四段活用の未然形・已然形（A-4・A-7）、下二段活用の動詞（流る・枯る・忘る）。

## shikibetsu-nari　「なり」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 断定（体言・連体形接続）と伝聞推定（終止形接続）の区別が、四段動詞のように終止形と連体形が同じ形の語ではつかない。音・声の場面という決め手を使えない（根拠：問「（隣の部屋で）人泣くなり」、本文の問 c10「人も《とふ》【なり】」・c16「と《奏す》【なり】」が伝聞推定）。→ S-51・S-54
  - 撥音便（あんなり・なんなり・ざんなり）を伝聞推定の目印として知らない（根拠：問「奥に人あんなり」）。→ S-52
  - 「静かなり」「清げなり」の形容動詞を、体言＋断定と混同する（根拠：問「清げなり」の誤答の選択肢「断定「なり」」）。→ S-53
  - 「春なれば」（断定）と「春になれば」（動詞）の区別（根拠：問 shikibetsu-nari-06）。→ S-51
  - 修正済み（2026-11-16）：c14 の解説の訳を例文（落窪の君の歌）の訳に、c10 の訳を歌の全訳に直した。c10・c16 に伝聞推定と決めた理由を足した。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 4つの正体：断定・伝聞推定（助動詞）、形容動詞の語尾、動詞「成る」（S-50）。
  - 手順1：体言・連体形＋なり＝断定、終止形＋なり＝伝聞推定、格助詞「に」＋なり＝動詞「成る」（S-51）。
  - 手順1の目印：撥音便（あんなり・なんなり・ざんなり、「ん」の無表記も）は伝聞推定（S-52）。
  - 手順3：前が名詞として使えなければ、「なり」までで1語の形容動詞（S-53）。
  - 手順4：終止形と連体形が同じ形なら、音・声を根拠にした文かどうかで決める（S-54）。
- **前提**（先に要る用語・単元）
  - 断定「なり」（jodoshi-dantei）、伝聞推定「なり」（jodoshi-nari）。
  - 終止形・連体形のちがい（上二段「落つ／落つる」、サ変「す／する」）、四段は同じ形（A-7）、音便（onbin）。
  - 形容動詞（ナリ活用、keiyoshi-katsuyo）。

## shikibetsu-shi　「し」の識別

### 分析
- **躓きポイント**
  - 実データ少（集計の基準に届いていない）。以下は解説とドリルの中身からの分析。
  - 過去「き」の連体形「し」と、サ変「す」の連用形「し」の区別。後ろの語（体言か、「て・けり」か）を見ていない（根拠：問「見し夢／物語しけり」、1文に2つの「し」がある問 shikibetsu-shi-w12）。→ S-61
  - 「せし」「こし（来し）」の特殊な付き方を知らない。「せし」をサ変連用形＋副助詞などと分けてしまう（根拠：問 shikibetsu-shi-08 の誤答の選択肢「サ変連用形「せ」＋副助詞「し」」、問 w05 の誤答の選択肢「しし事」）。→ S-62
  - 「恋しくて」の「し」を、「して」に見えてサ変と早合点する（根拠：問 shikibetsu-shi-w11 の解説「サ変「して」と早合点しない」）。→ S-63
  - 「過ぎにし年」の「にし」を、完了「に」＋過去「し」と分けられない（根拠：問 shikibetsu-shi-09・w07）。→ S-62
  - 修正済み（2026-11-16）：節「4つの「し」」と「判別の手順」に、形容詞の連用形（恋しく）の場合を入れた。w11 の正解を「形容詞の活用語尾（連用形「しく」の一部）」にした（先生の決定 25）。
  - 〔要確認〕S-63 の例「名にし負はば」の本文（texts-v3 東下り（都鳥）s10「名にし負はばいざこと問はむ都鳥…」）で、「こと問はむ」の「む」の意味ラベルが「意志」になっている。2026-11-16 の決定（いざ〜む＝勧誘）とそろっていない。台本ではこの「む」に触れていない。
- **解説ポイント**（この単元で必ず分かってほしいこと）
  - 4つの正体：過去「き」の連体形、サ変「す」の連用形、副助詞（強意）、形容詞の語尾（S-60）。
  - 手順2：し＋体言＝過去「き」の連体形、し＋て・けり・たり＝サ変「す」の連用形（S-61）。
  - 手順1：過去「き」は連用形に付く。カ変に「こし」、サ変に「せし」。「にし」＝完了「ぬ」の連用形＋過去「き」の連体形（S-62）。
  - 手順3：取り除いても意味が通る＝強めの副助詞（名にし負はば・折しも）。「し」までで1語＝形容詞の語尾（S-63）。
- **前提**（先に要る用語・単元）
  - 過去「き」の活用（（せ）・○・き・し・しか・○）と接続（jodoshi-jisei）。
  - サ変・カ変の活用（A-6）、形容詞のシク活用（keiyoshi-shiku）。
  - 連用形・連体形、体言。
