## 台本の決まり
- **説明（say）は先生ごとに変えない共通の文**。1文が1つの吹き出しになる。
  - 先生の口調は、説明のまわりの文（はじめ・つなぎ・ほめる・はげます・聞く・まとめ）に別に付ける（`src/lib/teacherLessonLines.ts`、予定）。
  - **単語クイズの台詞（`teacherLines.ts`）は使い回さず、レッスン用に新しく書く**（2026-11-15 ユーザー指示「コメントは単語のものを使い回さないで独自のもの」）。レッスンの中のドリルの答え合わせも、レッスン用の台詞にする。文法道場のドリル（復習を含む）の答え合わせも、文法用の新しい台詞にする（同日「ドリルも独自のコメントにして」）。
- 問い（checks）は、今説明したことを確かめる。
  - 誤答の選択肢は、実際の誤答と、よくある紛れから作る。
  - miss は、その誤答を選んだ人に見せる「なぜ違うか」。
- table は、その節の表をそのまま見せる。drillHeading は、その節のドリルの問いを1〜2問足す。
- ask と known は、生徒が押す選択肢の文。「〜を教えて」と「〜は分かってる（問題だけ）」。
- terms は、はじめに「〜って？」と聞ける用語。用語集の48語から選ぶ。
- 古典作品からの引用を作らない（捏造禁止）。例はドリルの例文・教材の本文（textExamples）、または作品名を付けない短い例（書かず・書きけり）だけにする。
- 確かでないことは 〔要確認〕 と書く。
